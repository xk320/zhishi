# 任务-000017：研究与决策复盘体系

- 状态：待执行
- 类型：研究 / 治理流程
- 阶段：阶段1理论体系固化阶段
- 来源：阶段规划
- 优先级：P1
- 关联任务：任务-000015、任务-000016
- 依赖任务：任务-000015（研究准入流程）、任务-000016（交易许可协议）
- 阻塞条件：研究准入和交易许可协议未稳定前，不进入执行链路

## 目标

建立《知势》研究、决策、许可结果的复盘体系，使每一次研究结论和交易许可结果都能够形成可追溯反馈，支持后续规则优化和能力迭代。

## 背景

当前《知势》已经完成：

- 研究准入流程；
- 知识图谱与版本合同；
- 决策委员会体系；
- 交易许可协议。

下一步需要建立闭环反馈机制，避免系统只产生结论而无法持续学习。

## 工作范围

包含：

- 研究复盘合同；
- 决策复盘合同；
- 许可结果与实际结果关联规则；
- 正确与错误判断分类；
- 反证记录；
- 规则优化反馈路径。

## 不在范围

不包含：

- 自动修改交易规则；
- 自动调整模型参数；
- 自动交易执行；
- 真实资金管理；
- 市场数据采集。

## 输入合同

复盘必须引用：

- 原始研究编号；
- 决策编号；
- 知识快照版本；
- 证据版本；
- 交易许可结果；
- 当时有效的风险约束。

## 输出合同

输出文件：

`docs/研究/决策复盘规范.md`

必须包含：

- 判断依据；
- 实际结果；
- 偏差分析；
- 错误来源；
- 反证情况；
- 是否需要新的研究任务。

## 原则

- 复盘不是为了证明预测正确，而是发现系统偏差。
- 历史决策不可覆盖，只能追加新的复盘记录。
- 复盘结果不能直接修改交易许可历史。
- 任何规则优化必须重新进入研究准入流程。

## 验证要求

执行：

- Markdown格式检查；
- 与研究准入、交易许可、知识图谱交叉检查；
- 任务中心一致性检查；
- git diff --check。

## 验收标准

- 完成决策复盘规范文档；
- 明确研究、决策、许可三层复盘边界；
- 支持未来历史重放和模拟交易复盘；
- 不实现自动交易和模型自动调整。

## 完成定义

- 提交PR；
- 架构评审通过；
- 合并后更新任务状态。
