## 背景

《知势白皮书》V1.0 的架构评审指出，第一阶段选择 BTC、ETH、SOL 的依据尚未形成正式、可复核的理论说明，容易被误解为经验选择。

## 任务目标

在白皮书中补充“第一阶段标的选择依据”，把候选标的范围写成待数据审计验证的研究假设和风险边界。

## 输入合同

- `《知势宣言》.md`
- `docs/白皮书/知势白皮书.md`
- `docs/研究/研究准入规范.md`
- 任务-000007 的任务合同与 Pull Request #9 当前版本

## 输出合同

- 更新 `docs/白皮书/知势白皮书.md`。
- 在任务文件和看板中记录真实验证结果及交付引用。

## 工作范围

1. 说明 BTC 的流动性、市场代表性、数据成熟度和研究价值。
2. 说明 ETH 的生态属性、与 BTC 资金关系的研究价值及独立资金行为研究价值。
3. 说明 SOL 的高 Beta 属性假设、资金轮动研究价值和风险收益特征。
4. 说明暂不扩展其他代币的原因，包括数据质量、流动性、样本不足和风险控制。
5. 明确上述依据须由后续数据资产审计重新验证。

## 不在范围

- 不以历史涨幅作为主要选择理由。
- 不新增其他研究标的。
- 不把尚未审计的判断表述为事实。
- 不进行模型训练、回测、真实交易或数据访问。

## 安全边界

- 不访问服务器、数据库或真实交易账户。
- 不修改或覆盖任何市场数据。
- 不声明未经证据支持的胜率、收益或因果关系。
- 不降低《知势宣言》和《研究准入规范》的门槛。
