# 任务-000013：建立 PR 自动合并策略与审批规则

- 状态：待执行
- 类型：治理
- 来源：架构优化
- 优先级：P1
- 关联问题：PR 合并流程存在人工阻塞

## 目标

建立《知势》PR 自动合并机制，使已完成架构评审并满足安全条件的变更可以自动进入合并流程。

目标流程：

任务中心
↓
Codex执行
↓
创建PR
↓
自动检查
↓
架构评审通过
↓
自动Merge
↓
更新任务状态

## 实施要求

新增 PR 自动化规则，包括但不限于：

1. 建立自动合并策略文档。
2. 建立 GitHub Actions 自动合并流程。
3. 定义不同任务类型的合并权限。
4. 更新 AGENTS.md。
5. 更新 Codex 自动执行规范。
6. 更新任务中心规范。

## 自动合并边界

允许自动合并：

- 文档任务
- 治理任务
- 研究规范任务

禁止自动合并：

- 交易执行代码
- 资金管理代码
- 生产环境配置
- 数据删除或迁移
- 涉及真实资金风险的修改

## 验收标准

- [ ] 存在明确的 PR 自动合并策略文档。
- [ ] 自动合并触发条件明确。
- [ ] 架构评审结果可以作为自动合并依据。
- [ ] 高风险变更仍保留人工审批。
- [ ] Codex 执行规则已同步。
- [ ] GitHub Actions 验证通过。

## 完成定义

- 提交PR。
- 通过架构评审。
- 合并后更新任务状态。
- 不降低《知势》的安全和质量门槛。
