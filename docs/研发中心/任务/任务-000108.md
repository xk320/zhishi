## 背景

现有文档已经分别描述研究准入和交易许可，但阶段1的数据门、研究生命周期、单次交易许可和真实资金关闭状态分散在多个入口中。若缺少明确的独立层级，数据证据通过可能被误解为研究已纳入，研究已纳入又可能被误解为可以接入真实交易。本任务把三个概念固定为不同对象、不同输入、不同输出和不同状态机，减少越权放行和状态误读。

## 任务目标

1. 定义三层边界：研究准入决定研究是否可在冻结范围内推进；交易许可决定单个冻结决策是否允许；真实交易准入决定系统是否具备使用真实资金的资格。
2. 固定禁止自动升级：研究准入不能生成交易许可，交易许可不能开启真实交易准入，阶段1数据门不能替代任一层的独立证据。
3. 将第一阶段输出拆为数据证据结论、允许研究范围、单次交易许可和真实交易准入状态，保持当前真实资金状态为`关闭`。
4. 更新研究准入规范、交易许可协议、数据验证阶段执行规范、总体计划和README，形成可复验的统一入口。

## 固定执行方案

1. 在`docs/superpowers/specs/2026-08-13-task-000108-research-trading-admission-separation-design.md`冻结三层模型、状态、输入、输出和禁止升级路径。
2. 更新《研究准入规范》：研究准入只裁决研究生命周期和适用研究范围，`已纳入`仍不得授予单次交易许可或真实交易准入。
3. 更新《交易许可协议》：单次许可继续只输出`允许/禁止`，新增真实交易准入作为独立系统级硬门；当前真实资金状态固定为`关闭`。
4. 更新阶段1执行规范、总体计划和README：阶段1数据门只提供研究准入的必要输入，阶段2和真实交易仍需独立门禁；模拟、影子决策和真实交易分别记录。
5. 只做文档、合同和派生入口修改，不实现运行时、数据库、模型、回测、模拟委托或真实交易。
