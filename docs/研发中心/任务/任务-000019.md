# 任务-000019：研究数据合同与实验记录规范

- 状态：待执行
- 类型：架构 / 研究治理
- 阶段：阶段2 数据真实性建设准备阶段
- 来源：理论体系完善
- 优先级：P1
- 依赖任务：任务-000015（研究准入流程）、任务-000017（研究与决策复盘）
- 阻塞条件：无；实际数据验证依赖任务-000003～000006完成数据资产准备

## 目标

建立《知势》研究数据与实验记录统一合同，使未来数据接入、历史重放、模型研究和复盘过程具备可追溯性。

## 背景

当前《知势》已经完成：

- 研究准入流程；
- 知识图谱与版本合同；
- 交易许可协议；
- 研究与决策复盘体系。

下一步需要定义研究过程中数据、实验和结果的版本关联规则，避免出现只有结论而无法重放依据的问题。

## 工作范围

包含：

- 数据版本合同；
- 实验记录合同；
- 参数版本记录；
- 结果版本记录；
- 历史重放引用规则；
- 与知识图谱、交易许可、复盘体系的关联规则。

## 不在范围

不包含：

- 数据采集实现；
- 数据库设计；
- 模型训练系统；
- 回测系统实现；
- 真实交易执行。

## 输入合同

定义研究实验必须引用：

- 数据来源；
- 数据版本；
- 数据截止时间；
- 实验参数版本；
- 研究假设版本；
- 环境信息。

## 输出合同

输出文件：

`docs/研究/研究数据合同与实验记录规范.md`

必须定义：

- 数据记录格式；
- 实验记录格式；
- 结果记录格式；
- 重放要求；
- 复盘引用方式。

## 原则

- 历史记录不可覆盖。
- 结论必须能够追溯到数据和实验版本。
- 数据不足时不得生成已验证关系。
- 实验结果不得替代交易许可。

## 验证要求

执行：

- Markdown检查；
- 任务中心一致性检查；
- 与研究准入、知识图谱、交易许可、复盘规范交叉检查；
- git diff --check。

## 验收标准

- 完成研究数据合同文档。
- 明确数据、实验、结果版本关系。
- 支持未来历史重放和研究复盘。
- 不实现数据系统和交易系统。

## 完成定义

- 提交PR。
- 架构评审通过。
- 合并后更新任务状态。
