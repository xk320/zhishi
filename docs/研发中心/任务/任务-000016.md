# 任务-000016：交易许可协议 V1.0

- 状态：待执行
- 类型：架构 / 决策协议
- 来源：阶段规划
- 优先级：P0
- 关联任务：任务-000014

## 目标

建立《知势》最终交易许可输出协议，将研究结果、证据状态、风险约束和执行条件统一转换为可审计的交易许可结果。

## 背景

当前《知势》已经完成：

- 白皮书方法论；
- 决策委员会职责体系；
- 知识图谱与运行时合同。

下一步需要定义系统最终输出合同，避免不同模块产生不一致的交易结论。

## 实施要求

定义交易许可输入：

- 市场状态；
- 资金状态；
- 风险状态；
- 证据状态；
- 成本状态；
- 执行条件。

定义交易许可输出：

- 交易许可：允许 / 禁止；
- 标的；
- 时间尺度；
- 方向；
- 证据引用；
- 主要反证；
- 风险约束；
- 失效条件；
- 仓位约束；
- 复盘要求。

## 原则

- 默认结果不是交易，而是禁止交易。
- 禁止未经证据支持的胜率、收益承诺。
- 禁止单一指标绕过质量门。
- 交易许可必须可追溯到知识版本和证据版本。

## 验收标准

- 完成交易许可协议文档。
- 与白皮书、决策委员会、知识图谱保持一致。
- 明确允许和禁止两类最终状态。
- 支持未来模拟交易、历史重放和复盘。
- 不实现交易代码，不接入真实资金。

## 完成定义

- 提交PR。
- 架构评审通过。
- 合并后更新任务状态。
