## 背景

任务-000080和任务-000081已确认仓库内显式声明入口为空，任务-000077的数据库结构观察也不能证明来源、市场、合约或授权。阶段1八个BTC/ETH研究叶子因此全部阻塞。本任务只在既有白名单根目录和固定数据库元数据范围内寻找显式声明，证据不足时保留未知，不修改订单簿逻辑或原始数据。

## 任务目标

1. 冻结执行时最新`main`、任务-000081成员顺序、输入指纹和既有来源身份声明配置。
2. 在合同规定的仓库配置、白名单根目录声明文件和数据库表/列注释摘要中发现候选入口，记录入口版本、唯一定位、内容指纹和授权边界。

4. 追加不可变批次并精确更新`ZS-DATA-GAP-001`；入口为空或证据不足时，明确记录`未登记`/`无法判定`、原因和解除条件。

## 固定执行方案

1. 从最新`main`只读加载任务-000081快照、成员清单、资产清单、来源身份合同、缺口台账和历史批次，按`标的、资产编号、成员编号`冻结顺序并复算指纹。
2. 仅读取仓库两个已登记声明配置；远端只通过`ubuntu`无交互、串行、有界探针检查配置允许根目录下四个精确文件名；拒绝隐藏目录、未登记路径、符号链接、可执行文件和超限文件。

4. 对候选声明执行字段完整性、成员绑定、Schema/授权指纹、撤销事实、敏感扫描、状态守恒和计数守恒校验；任一失败安全条件停止相关发布。
