# 任务-000023：市场事件层架构设计

- 状态：执行中
- 类型：架构 / 市场事件建模
- 阶段：阶段2 数据真实性验证与研究能力建设阶段
- 优先级：P0
- 执行分支：`codex/000023-market-event-layer-architecture-v1`

## 依赖任务

- 任务-000006：设计最小数据闭环、存储方案并形成最终审计结论
- 任务-000021：Market Regime 市场状态架构设计

## 目标

建立《知势》市场事件层（Market Event Layer），连接市场状态与历史结果，将人工交易分析中的市场行为转换为可记录、可重放、可验证的事件合同。

## 工作范围

包含：

- 市场事件定义；
- 事件分类体系；
- 事件输入合同；
- 事件结果合同；
- 状态与事件关联关系。

## 不在范围

不包含：

- 交易信号生成；
- 收益预测；
- 模型训练；
- 自动下单；
- 真实交易执行。

## 事件类型初始范围

包括但不限于：

- 突破事件；
- 跌破事件；
- 放量上涨事件；
- 放量下跌事件；
- 缩量回调事件；
- 趋势切换事件；
- BTC、ETH、SOL联动事件。

## 验收标准

- 完成市场事件层架构文档；
- 定义事件Schema；
- 定义事件结果合同；
- 明确历史重放要求；
- 更新任务中心与看板；
- 通过研发中心验证。

## 安全约束

- 市场事件不是交易信号；
- 不输出预测结论；
- 不使用未来数据；
- 状态不确定时必须保守处理。
