## 固定执行方案

采用方案A“可见性合同优先的离线双门重放”，不得替换为投票、模型预测或经验时间窗。

### 第一门：输入与可见性资格

对每个验证单元依次检查：

1. 资产是否在冻结清单中且批次、身份和质量证据一致；
2. 是否存在带时区的真实决策时点；
3. 事件时间、到达时间、采集时间是否分别有版本化语义合同；
4. 到达时间是否不晚于决策时点；
5. 输入是否完整扫描且未在结构、冻结和重放阶段发生身份漂移。

任一项无法证明时，该验证单元不得进入正式状态重建，结论为`无法判定`或`拒绝`，并
记录具体缺失证据和解除条件。

### 第二门：确定性重建与未来数据拒绝

只有通过第一门的验证单元才能执行：

1. 以`到达时间 <= 决策时点`构造当时可见集合；边界使用包含决策时点的闭区间；
2. 按已冻结的业务键和稳定次序生成规范快照；没有业务键时不得猜测去重规则；
3. 对同一输入、决策时点和规则连续重放两次，比较记录数和SHA-256快照指纹；
4. 在`smoke-only`测试中注入到达时间晚于决策时点的记录，验证器必须拒绝并返回固定
   原因码`future_arrival_rejected`；
5. 任一次结果不同、出现身份漂移或未来记录进入快照，正式结论必须为`拒绝`。
