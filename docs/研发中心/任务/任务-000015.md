# 任务-000015：研究准入流程完善

- 状态：待执行
- 类型：研究 / 治理流程
- 阶段：阶段1 理论体系固化阶段
- 来源：阶段规划
- 优先级：P0
- 依赖任务：无
- 关联任务：任务-000014、任务-000016
- 阻塞条件：无；若研究对象缺少明确假设、数据需求或验证方案，不得进入决策链路

## 目标

建立《知势》研究准入流程，使新的研究想法经过标准化流程后，才能进入知识体系、模型研究或交易许可流程。

## 背景

当前《知势》已经完成：

- 白皮书方法论；
- 决策委员会职责体系；
- 知识图谱与运行时合同；
- 交易许可协议。

下一步需要定义研究从提出到验证、淘汰、准入的完整生命周期，避免未经验证的指标、观点或策略直接进入决策体系。

## 工作范围

包含：

- 研究假设合同；
- 研究问题定义；
- 数据需求定义；
- 实验设计要求；
- 验证标准；
- 准入与淘汰规则；
- 与知识图谱、交易许可协议的关联规则。

## 不在范围

不包含：

- 实际市场数据采集；
- 模型训练实现；
- 回测系统实现；
- 交易执行代码；
- 真实资金交易。

## 输入合同

研究准入必须接收：

- 研究问题；
- 可证伪假设；
- 适用标的范围；
- 时间尺度；
- 数据需求；
- 验证方法；
- 风险边界。

## 输出合同

输出文件：

`docs/研究/研究准入规范.md`

输出必须包含：

- 研究状态；
- 验证结果；
- 证据引用；
- 准入或淘汰结论；
- 失效条件。

## 原则

- 假设不得直接成为规则。
- 相关性不得直接升级为因果关系。
- 无法验证的研究不得进入交易许可。
- 失败研究必须保留记录，不得删除历史。

## 验证要求

执行：

- Markdown格式检查；
- 任务中心一致性检查；
- 与白皮书、知识图谱、交易许可协议交叉检查；
- 状态生命周期检查；
- git diff --check。

## 验收标准

- 完成研究准入规范文档。
- 明确研究生命周期。
- 明确准入、淘汰和失效条件。
- 支持未来历史重放和研究复盘。
- 不实现数据采集、模型或交易执行。

## 完成定义

- 提交PR。
- 架构评审通过。
- 合并后更新任务状态。
