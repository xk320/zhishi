# 任务-000089：root 候选身份索引复验合同

<!-- markdownlint-disable MD013 -->

## 目的

在任务-000084固定的 root 兼容只读合同内，按候选文件名建立有界索引，避免普通非候选文件数量触发任务-000088的提前失败安全。索引发现不是来源身份声明；本合同不解除任务-000084、`ZS-DATA-GAP-001`或阶段1门禁。

## 固定范围与资源

- 远端目标只能是逻辑别名 `ubuntu`，固定探针为 `ssh -o BatchMode=yes -o ConnectTimeout=15 -o ServerAliveInterval=5 -o ServerAliveCountMax=1 ubuntu python3 -`。
- 只遍历任务-000084列出的六个根目录，识别八类候选文件名和 CSV/JSON/SQLite/DB 元数据；不跟随符号链接，排除 `/proc`、`/sys`、`/dev`、`/run`、`/tmp`、`/var/tmp`。
- 索引资源固定为：目录最多16,384个、目录条目最多262,144个、待处理目录最多16,384个、单路径最多4,096字节、候选摘要聚合最多32MiB；候选文件最多4,096个、单候选最多16MiB、公开API响应最多16MiB、输出最多32MiB、日志最多64KiB、批次总时限900秒。
- 任一索引或输出上限触发即清空候选、记录原因代码和指纹、失败安全；不得以部分候选生成来源身份输入。

## 身份复验

- BTC、ETH各315个成员和输入成员SHA-256来自任务-000083最终冻结顺序。
- 只有来源提供者、交易场所、市场类型、标的身份、精确合约、数据对象、Schema确切版本、授权边界和字段中文映射九项字段全部完整、当前、无冲突且可定位时，才允许进入`source-identity-evidence-1.0`。
- 不跨标的补偿、不缩小分母、不在结果可见后改变分组；缺失、冲突或失败保持`无法判定`或失败安全状态。

## root 语义与安全

本合同明确允许使用逻辑别名 `ubuntu` 登录实际 UID=0 的 root 用户；root 只用于固定探针的兼容只读执行，不等价于专用只读 UID=1001，也不产生更宽权限。批次必须记录实际 `uid=0`、`访问模式=root兼容只读`、协议、完整性、失败安全、失败原因指纹和资源事实；`扫描是否专用只读`必须为 `false`。候选自身、上级目录和候选根目录只保留路径指纹。不写远端、不创建临时文件、不执行DDL、不修改权限/服务/防火墙，不读取价格、成交、订单簿、账户、凭据、环境变量或未登记路径。

固定探针以标准输入运行，除该探针外不得执行任意 root 命令、任意 shell 参数或扩大目录、文件名、字段和数据库读取范围。

## 状态边界

任务-000089交付PR不得修改任务-000084合同或状态。即使发现完整结构化证据，也只能通过独立的合并后状态闭环PR恢复任务-000084；本任务完成不代表阶段1或阶段2完成。
