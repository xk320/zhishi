# 阶段1事前冻结数据资格决策与重放合同

<!-- markdownlint-disable MD013 -->

## 适用范围

本合同只验证任务-000094已冻结的数据资格证据能否在事前截止、独立决策和两个后续独立进程中确定性重放。它不恢复任务-000094缺失的微秒级原决策时间，不读取原始市场数据，不证明策略、模型、回测或交易决策可重放。

## 固定状态机

```text
不存在意图 → prepare发布意图并退出
已发布意图 → decide发布决策并退出
已发布决策 → replay发布第一份证明并退出
已有第一份证明 → replay发布第二份证明并退出
```

四次调用必须具有不同进程编号。每个阶段使用内核原子no-replace原语发布，随后追加不可变发布标记；完成证据内容寻址绑定阶段内除自身外的完整普通文件集合、逐文件字节数和SHA-256，发布标记同时绑定完成证据SHA和文件清单SHA。后继进程必须重新枚举和复算全部前序阶段文件，只有复核完成证据与发布标记后才记录阶段开始时间。任何目标已存在、晚到目标、阶段越序、输入或外层门禁字段漂移、文件集合变化或同一重放槽重复使用都失败，不覆盖既有输出。

## 事前冻结

`prepare`只读取配置、Git固定身份、预登记SHA声明和路径元信息。它必须在打开成员、连续段、叶子和来源拒绝载荷前取得精确UTC数据截止并追加式发布意图，然后退出。它不得计算成员最大时间，不得读取成员结果，不得执行来源载荷复核。

意图绑定任务、配置、合同、执行器、任务-000094合并提交、来源批次相对路径、预登记7文件SHA、来源批次指纹和数据截止。输入路径从仓库根逐组件检查；符号链接、越界或未知类型失败。

## 决策与重放

`decide`只接受已经发布的意图，逐字节复核7个来源文件后加载脱敏证据。每个正式成员的`source_visible_at`与`collected_at`必须不晚于事前数据截止。决策身份记录意图SHA、决策时间、输入成员顺序、版本和规范结果SHA。

两个`replay`进程均在决策发布后重新打开意图、决策及7个来源文件，分别从零派生结果。两份证明的规范结果SHA必须与决策一致，且进程编号和开始时间均不同于决策及彼此。

## 分母与裁决

固定保留5387个候选、5180个正式成员、4789个已证明、391个质量拒绝、207个来源拒绝、2个观察项、175个连续段和8个叶子。BTC、ETH、合约、数据对象和尺度分别裁决，禁止交叉补偿。

只有8个叶子的历史重放门可更新为`通过`。成本与执行、研究容量和隔离恢复继续为`无法判定`；8个叶子的总决策仍为`阻塞`，阶段1与阶段2均不放行。

## 发布与资源

`decide`和两个`replay`先写同父目录临时目录，回读输出后第三次复核全部来源，再写入包含完整文件清单、最终预提交资源测量和精确发布字节数的完成证据，回读完成证据后重测硬门；全部通过时才用内核原子no-replace原语发布。每个后继阶段重新复算全部前序阶段文件集合与SHA；每个进程最大RSS 512MiB、最长120秒、最多6000成员、单文件5MiB和输出25MiB。

正式执行只读任务-000094约1.3MiB脱敏批次，禁止遍历、读取、复制或再次扫描854GB原始归档，禁止访问Ubuntu、数据库、网络、凭据或生产系统。
