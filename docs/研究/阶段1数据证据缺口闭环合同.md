# 阶段1数据证据缺口闭环合同

<!-- markdownlint-disable MD013 -->

本合同对应任务-000061，目标是使用同一套不可变输入链，重新取得来源身份和时间质量证据，
而不是用一次可达性预检替代数据准入。

## 固定范围

- 前向标的：BTC、ETH，分别统计，禁止互相补偿。
- 主研究尺度：4小时、8小时、24小时、48小时。
- 15分钟、1小时：仅为事后结果观察窗口。
- 来源身份维度：来源提供者、交易场所、市场类型、标的身份、精确合约、数据对象、Schema
  确切版本、授权边界、字段中文映射。
- 时间质量维度：事件时间、到达时间、采集时间、时区/精度、数据截止、频率、业务键、排序、
  迟到、补录、撤销、修订、重复、断档、异常和时钟漂移。

## 证据规则

1. 资产路径、文件名、表名、字段名和常识不能证明业务身份。
2. 没有字段级、版本化、带指纹的证据时，状态必须为`无法判定`。
3. 失败、漂移、超时和越权保持失败安全；历史批次只读、不可覆盖。
4. 事件时间不得用文件修改时间替代；到达时间不得用采集时间替代；采集时间不得用文件时间替代。
5. 频率、时区或业务键未知时，不计算断档、不去重、不排序、不删除和不修订原始记录。

## 阶段门影响

本合同的批次即使全部通过，也只关闭对应来源身份和时间质量缺口，不自动关闭质量、重放、
成本、血缘、容量或恢复硬门。所有硬门通过前，阶段2、模型、正式回测和交易许可仍保持禁止。

## 可复现要求

每个批次必须保存：合同版本、任务文件指纹、输入清单指纹、规则指纹、执行器指纹、成员顺序、
状态计数、解除条件、资源实测和安全声明。新输入、规则或代码版本必须追加新批次，不能修改旧批次。
