# 《研究准入规范》

## 一、目的

本规范用于防止《知势》演变为指标堆砌系统。任何指标、特征、模型、规则或数据源，只有在证明其能够提高决策质量、降低风险或减少无效交易后，才允许进入生产系统。

## 二、最高准入原则

> 不能证明有优势，就默认不纳入。

复杂度本身不构成价值。新方法必须优于明确基准，并在交易成本、滑点、延迟和样本外条件下仍然成立。

## 三、标准研究流程

每项研究必须建立独立文档，并包含以下内容：

1. 研究编号与名称。
2. 决策问题：该研究具体帮助系统回答什么问题。
3. 研究假设：必须可以被数据证伪。
4. 适用标的与时间尺度。
5. 数据来源、时间范围与数据质量说明。
6. 基准方案。
7. 特征与计算定义。
8. 验证方法。
9. 交易成本、滑点和延迟假设。
10. 样本内结果。
11. 样本外结果。
12. 分市场状态结果。
13. 失败样本与负面证据。
14. 稳健性与敏感性分析。
15. 结论：纳入、继续研究或淘汰。

## 四、最低验收标准

一项研究进入候选能力库，至少需要满足：

- 数据不存在明显前视偏差、幸存者偏差和时间穿越。
- 明确记录手续费、资金费率、滑点和执行延迟。
- 使用按时间切分的样本外验证，不得随机打乱时间序列替代前推验证。
- 与无策略、简单趋势、简单相对强弱等基准比较。
- 在至少两个标的或两个独立市场阶段中验证。
- 报告胜率、盈亏比、期望收益、最大回撤、交易次数和空仓比例。
- 报告置信区间或重采样稳定性，不得只给单一最佳值。
- 参数小幅变化后结果不得立即崩溃。
- 对失败案例进行归因，而不是只展示成功样本。

## 五、正式纳入生产的附加条件

- 对“交易次数是否减少、交易质量是否提高”有明确贡献。
- 在真实数据延迟和真实执行约束下运行稳定。
- 有监控指标、失效告警和降级方案。
- 能解释其主要支持证据与主要反证。
- 不与《知势宣言》和风险纪律冲突。
- 新增复杂度与预期增益相匹配。

## 六、一票否决条件

出现以下任一情况，研究不得纳入：

- 使用未来数据或无法证明时间对齐正确。
- 只在单一行情、单一月份或单一标的有效。
- 收益主要来自极少数异常交易。
- 忽略手续费、资金费率或滑点后才有收益。
- 通过大量参数搜索得到孤立最优点。
- 无法复现研究结果。
- 只提高表面胜率，却显著恶化盈亏比或最大回撤。
- 提高交易频率，但未提高净期望收益。
- 模型无法输出可执行的失效条件。

## 七、研究状态

每项研究只能处于以下状态之一：

- `提议`：尚未开始。
- `验证中`：正在进行数据和实验验证。
- `候选`：通过最低标准，等待更严格验证。
- `试运行`：进入模拟或影子决策环境。
- `已纳入`：进入正式决策链路。
- `已淘汰`：证据不足或不符合系统原则。
- `已失效`：曾经有效，但当前市场或数据条件下失效。

## 八、研究编号规则

```text
ZS-研究-年份-四位序号
```

示例：

```text
ZS-研究-2026-0001：相对强度持续性是否提高未来8小时标的选择质量
```

## 九、统一结论模板

```text
研究结论：候选 / 继续研究 / 淘汰
证据强度：弱 / 中 / 强
适用范围：
不适用范围：
预期贡献：
主要风险：
下一步验证：
```

《知势》不奖励复杂模型，只奖励经得起证伪的有效方法。
