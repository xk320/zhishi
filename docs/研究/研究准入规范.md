# 《知势研究准入规范》V1.0

> 不能证明有优势，就默认不纳入。

- 文档性质：研究生命周期、证据准入与淘汰合同
- 适用对象：指标、特征、关系、规则、模型、数据源与研究方法
- 当前生产状态：数据审计任务已交付但阶段1证据门未通过，真实资金交易关闭

## 一、目的与边界

本规范用于防止《知势》演变为指标堆砌系统。任何指标、特征、模型、规则或数据源，
只有在证明其能够提高决策质量、降低风险或减少无效交易后，才可能进入知识体系。

本规范定义从研究提议、验证、候选、试运行、纳入、淘汰到失效的完整流程。它不：

- 采集或修改市场数据；
- 实现模型训练、回测系统或实验运行器；
- 规定未经数据验证的具体阈值；
- 实现知识图谱运行时；
- 授予交易许可或触发交易执行；
- 启用模拟交易或真实资金交易。

研究准入只回答“研究证据是否达到指定阶段”。它不回答当前是否存在交易机会，
也不能替代《知势交易许可协议》的七道质量门。

## 二、最高准入原则

复杂度本身不构成价值。新方法必须优于明确基准，并在交易成本、滑点、延迟和样本外
条件下仍然成立。

研究过程必须遵守：

1. **决策问题先行：** 每项研究只能服务于一个明确决策问题。
2. **假设可证伪：** 必须事先定义什么证据会反对或推翻假设。
3. **版本不可变：** 已形成结论的研究版本不得覆盖；变化必须生成新版本。
4. **时间可见：** 历史验证只使用当时已经到达的数据。
5. **基准优先：** 新方法必须与无策略或简单方法比较。
6. **成本完整：** 手续费、滑点、资金费率和执行延迟必须进入验证。
7. **支持与反证并存：** 主要失败样本和反证不得省略。
8. **范围不外推：** 标的、尺度、市场状态和时间范围必须逐项匹配。
9. **失败可保留：** 淘汰、失效和无法判定都是正式结果，不得删除历史。
10. **默认不纳入：** 缺失、冲突、不可重放或无法判定时不得升级状态。

研究达到`已纳入`也不能绕过数据、样本、优势、成本、风险、执行、频率与纪律质量门。

## 三、输入合同与研究版本

### 3.1 必需输入

| 输入 | 必需内容 | 缺失时处理 |
| --- | --- | --- |
| 研究问题 | 唯一决策问题及预期减少的错误交易或增强的风险约束 | 保持提议 |
| 可证伪假设 | 方向、对象、条件和可观察反证 | 不得验证 |
| 适用范围 | 标的、时间尺度、市场状态、有效时间和不适用范围 | 不得进入候选 |
| 数据需求 | 来源、三类时间、字段、质量、版本、样本量和重放要求 | 不得进入候选 |
| 验证方法 | 时间切分、基准、成本、稳健性、校准和失败样本方法 | 不得开始验证 |
| 风险边界 | 可能增加的错误、尾部风险、降级方式和不得放宽的门槛 | 不得进入候选 |

适用标的只限第一阶段的BTC、ETH，主时间尺度只限4小时、8小时、24小时、
48小时。不得在BTC与ETH之间互相替代证据，也不得跨尺度或跨市场状态静默外推。

### 3.2 研究编号与版本

研究编号使用：

```text
ZS-研究-年份-四位序号
```

示例：

```text
ZS-研究-2026-0001
```

研究编号标识长期研究问题。定义、数据、方法、参数、作用域、证据或结论变化时，
必须创建新的研究版本。

每个研究版本至少保存：

```text
研究编号
研究版本
前序研究版本
研究名称
决策问题
创建时间与冻结时间
生命周期状态
验证结果
适用范围与失效条件
数据、方法、配置和证据版本集合
完整性指纹
```

研究版本冻结后不得修改。勘误、补充证据、重新验证、恢复研究或改变适用范围都必须
生成新版本，并保留前序版本和旧结论。

## 四、标准研究流程

每项研究必须建立独立记录，并按顺序完成：

1. 登记研究编号、名称与决策问题。
2. 写出可被数据证伪的假设和主要反证。
3. 定义适用标的、时间尺度、市场状态与不适用范围。
4. 定义数据来源、三类时间、范围、质量和可重放要求。
5. 在查看验证集结果前冻结基准、参数和准入标准。
6. 完整定义特征、公式、单位和计算顺序。
7. 按时间划分样本内、验证集和样本外区间。
8. 定义滚动或前推验证方法，不得随机打乱时间序列替代前推。
9. 计入手续费、滑点、资金费率、执行延迟和安全余量。
10. 报告样本内、样本外和分市场状态结果。
11. 报告失败样本、主要反证与同源证据关系。
12. 执行参数、时间、标的、成本与重采样稳健性分析。
13. 若输出概率，报告校准方法、校准误差和区间估计。
14. 与简单基准比较成本后、风险后增量价值。
15. 记录影响的交易许可质量门和失败时的降级方式。
16. 复现冻结版本并记录环境、代码、配置和随机种子。
17. 根据证据形成状态转换申请，不得原地覆盖结论。

禁止先看到样本外结果，再调整问题、方向、窗口或阈值，使原假设看似成立。

## 五、最低验收标准

一项研究进入候选，至少需要满足：

- 数据不存在明显前视偏差、幸存者偏差和时间穿越；
- 数据来源、事件时间、到达时间、采集时间和版本可追溯；
- 明确记录手续费、资金费率、滑点和执行延迟；
- 使用按时间切分的样本外验证，不得随机打乱时间序列；
- 与无策略、简单趋势、简单相对强弱等基准比较；
- 在至少两个标的或两个独立市场阶段中验证；
- 报告胜率、盈亏比、单笔净期望、最大回撤、交易次数和空仓比例；
- 报告置信区间或重采样稳定性，不得只给单一最佳值；
- 若输出预测胜率，报告校准指标、误差和区间；
- 预测胜率与确定性、证据完整度和模型置信度分离；
- 参数小幅变化后结果不立即崩溃；
- 对失败案例归因，而不是只展示成功样本；
- 明确该研究影响哪个决策问题与交易许可质量门；
- 定义可观察的失效条件、监控要求和安全降级。

若没有足够样本，验证结果必须为`无法判定`，不得填入推测值。

## 六、研究状态与合法转换

### 6.1 生命周期状态

每项研究只能处于以下状态之一：

| 状态 | 含义 | 能否支持预测性交易许可 |
| --- | --- | --- |
| 提议 | 已登记问题，尚未取得验证资格 | 否 |
| 验证中 | 合同已冻结，正在验证或等待可验证输入 | 否 |
| 候选 | 通过最低标准，等待影子环境验证 | 否 |
| 试运行 | 仅进入模拟或影子决策，持续收集证据 | 否 |
| 已纳入 | 已完成研究与治理评审，可申请进入激活清单 | 仅作为匹配范围的一项必要证据 |
| 已淘汰 | 未证明增量价值、违反硬门或不值得继续 | 否 |
| 已失效 | 试运行或已纳入后，当前证据或条件不再适用 | 否 |

试运行不允许真实资金；已纳入也不等于交易许可允许。

### 6.2 允许的状态转换

| 当前状态 | 允许到达 | 最低条件 |
| --- | --- | --- |
| 提议 | 验证中、已淘汰 | 输入合同完整；或已有明确停止证据 |
| 验证中 | 候选、已淘汰 | 最低验收通过；或已有明确否决证据 |
| 候选 | 试运行、验证中、已淘汰 | 试运行计划；补充验证要求；或淘汰证据 |
| 试运行 | 已纳入、候选、已失效 | 影子结果、风险影响、失效监控和治理评审 |
| 已纳入 | 已失效 | 新反证、数据问题、范围变化、监控失败或合同不兼容 |
| 已淘汰 | 验证中 | 新证据、重新立项评审和新研究版本 |
| 已失效 | 验证中 | 解除条件证据、重新评审和新研究版本 |

表外转换全部禁止。尤其禁止提议、验证中或候选直接进入已纳入，也禁止把已淘汰或
已失效的旧版本原地改回已纳入。

候选发现证据或条件不再满足时，应退回`验证中`或进入`已淘汰`；只有试运行或已纳入
研究可以进入`已失效`。

### 6.3 状态转换记录

每次转换必须保存：

```text
转换编号
研究编号与研究版本
原状态、申请状态与裁决状态
验证结果
支持证据版本集合
主要反证版本集合
适用范围与失效条件
申请时间与裁决时间
评审引用
中文原因
```

记录缺失、版本冲突或评审不完整时，状态保持不变。

## 七、准入、淘汰与失效

### 7.1 候选、试运行与已纳入

进入候选必须通过第五节全部最低标准。候选只表示值得进行更严格验证，不表示已经
纳入知识快照。

进入试运行还必须：

- 有明确影子决策或模拟验证计划；
- 不写入真实交易账户；
- 结果与许可和执行记录分离保存；
- 监控数据质量、概率校准、成本、漂移和异常；
- 预先定义暂停、退出和回退条件。

进入已纳入还必须：

- 试运行结果满足预注册标准；
- 数据、证据、规则和研究版本一致；
- 失效条件可观察且监控可执行；
- 研究评审与知识治理评审通过；
- 知识节点或关系、证据状态及作用域明确。

已纳入只获得“可申请进入激活清单”的资格，不自动进入清单，也不自动授予交易许可。

### 7.2 一票否决与淘汰

出现以下任一情况，研究必须淘汰：

- 假设不可证伪或不能映射到决策问题；
- 使用未来数据或无法证明时间对齐；
- 只在单一行情、单一月份或单一标的有效；
- 收益主要来自极少数异常交易；
- 忽略手续费、资金费率或滑点后才成立；
- 通过大量参数搜索得到孤立最优点；
- 无法复现；
- 只提高表面胜率，却恶化盈亏比、净期望或最大回撤；
- 提高交易频率，但未提高成本后净期望；
- 不能提供可执行失效条件；
- 把评分、模型置信度或语言模型判断冒充预测胜率；
- 需要放宽既有风险门槛才能成立；
- 新增复杂度却没有可证明增量价值。

淘汰记录必须保留问题、版本、失败原因、反证、适用范围和重新立项条件。

### 7.3 失效

试运行或已纳入研究出现以下任一情况时，必须评估失效：

- 数据源、字段、时间语义或质量发生不兼容变化；
- 预测概率持续失校准；
- 成本、流动性或执行延迟使净优势消失；
- 标的、尺度或市场状态超出验证范围；
- 参数或结果稳定性跌破预注册标准；
- 新反证推翻关键假设；
- 依赖知识、规则或风险合同失效；
- 无法重放当前使用的研究证据；
- 监控中断且无法证明继续使用安全。

影响预测性关系、关键风险约束或当前知识快照时，默认停止新激活。后续决策在重新
取得合格证据前必须输出交易许可禁止，不得沿用缓存结论。

## 八、输出合同

每个冻结研究版本必须输出：

```text
研究编号
研究版本
研究名称
研究状态
决策问题
可证伪假设
适用范围与不适用范围
数据、方法和配置版本集合
验证结果
支持证据引用
主要反证与失败样本引用
基准、成本与风险结果
准入或淘汰结论
失效条件
降级方式
知识图谱映射候选
影响的交易许可质量门
下一步验证或停止原因
完整性指纹
```

输出约束：

- `研究状态`只能使用七种生命周期状态；
- `验证结果`只能为`支持假设`、`反对假设`或`无法判定`；
- `准入或淘汰结论`只能为`准入下一阶段`、`继续验证`、`淘汰`或`失效`；
- 证据必须引用确切不可变版本，摘要和网页链接不能替代来源；
- 失效条件必须可观察，无法定义时不得进入候选；
- 不适用字段必须写`不适用`并说明原因，不能留空或猜测。

## 九、知识图谱与交易许可隔离

### 9.1 生命周期与证据状态分离

研究生命周期状态不能自动推导知识关系的证据状态。经验性关系只能按以下方向申请：

```text
待验证假设 → 相关观察 → 已验证关系
```

- 单一标的或单一市场阶段最多支持`相关观察`；
- 只有通过准入、作用域明确且可重放的研究，才可申请`已验证关系`；
- 申请仍需知识治理评审，不能由研究执行者自行批准；
- `规范约束`和`派生定义`不能证明市场因果。

研究状态变化不能自动改写知识节点、关系、证据状态或激活清单。

### 9.2 交易许可隔离

预测性研究只有同时满足以下条件，才可能作为未来优势证据：

1. 生命周期为`已纳入`；
2. 关系证据状态为`已验证关系`；
3. 研究、证据和知识版本可追溯；
4. 标的、尺度、市场状态与有效时间匹配；
5. 对应版本已进入当前作用域的激活清单；
6. 数据、样本、成本、风险和执行条件仍有效；
7. 没有未解决的失效或版本冲突。

即使全部满足，它也只是交易许可的一项必要输入。提议、验证中、候选、试运行、
已淘汰、已失效、待验证假设、相关观察和作用域不匹配的已验证关系，都不得支持
`交易许可：允许`。

缺失、冲突、超时或无法确认状态时：

```text
交易许可：禁止
建议仓位：0
```

## 十、历史重放、复盘与历史保留

### 10.1 历史重放

研究重放必须加载原研究版本绑定的：

- 原始与派生数据版本；
- 事件时间、到达时间、采集时间和数据截止时间；
- 代码、配置、环境与随机种子；
- 样本切分、参数和基准版本；
- 成本、延迟与风险假设；
- 支持、反证与失败样本版本。

使用事后修订数据或当前“最新版本”得到相似结果，不能证明原研究可重放。

### 10.2 研究复盘

复盘必须检查假设、数据、预注册方案、支持与反证、异常样本、成本、风险、状态转换
和实际增量价值。单次后续盈利不能复活淘汰研究，单次亏损也不能直接使合规研究失效。

复盘只能提出新版本、补充验证、淘汰或失效申请，不能修改历史记录。

### 10.3 历史保留

- 不删除淘汰或失效研究；
- 不覆盖旧版本结果；
- 不移除失败样本或主要反证；
- 不因新版本通过而修改旧版本结论；
- 不因研究未触发交易而省略复盘；
- 不把无结果或无法判定写成成功。

## 十一、异常与安全降级

| 异常 | 处理 | 是否允许状态升级 |
| --- | --- | --- |
| 必需输入缺失 | 记录字段和来源，不猜测补齐 | 否 |
| 数据或版本冲突 | 冻结当前流程并列出冲突 | 否 |
| 样本不足 | 验证结果记为无法判定 | 否 |
| 重放失败 | 保留运行记录并调查血缘 | 否 |
| 评审超时 | 状态保持不变 | 否 |
| 监控中断 | 停止新激活并评估失效 | 否 |
| 未知异常 | 安全停止并记录审计事件 | 否 |

日志和研究记录不得包含密钥、密码、令牌、账户凭据或不必要的个人信息。

## 十二、验收场景

未来实现至少覆盖：

1. 缺少决策问题或可证伪假设时保持提议；
2. 未冻结验证方法时不能进入验证中；
3. 数据三类时间不完整时不能进入候选；
4. 忽略成本后才成立的研究必须淘汰；
5. 单一标的或单一阶段结果最多形成相关观察；
