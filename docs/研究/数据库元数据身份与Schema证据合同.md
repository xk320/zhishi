# 数据库元数据身份与Schema证据合同

<!-- markdownlint-disable MD013 -->

本合同对应任务-000077。它只复采数据库对象的结构元数据，为任务-000076的来源身份证据提供可复算输入；结构存在不等于来源身份、时间质量、数据质量、研究准入或交易许可成立。

## 证据身份

每个成员使用以下不可变关联键：

```text
任务-000076来源身份批次 + 资产编号 + 来源成员编号 + 输入成员SHA-256 + Schema/表 + 探针版本
```

复采范围固定为`information_schema.TABLES`和`information_schema.COLUMNS`。输出只保存数据库、Schema、表、列的脱敏指纹、列顺序摘要、类型摘要、规则版本、授权边界快照指纹和状态，不保存业务行、价格、成交、订单簿、账户或凭据。

## 状态语义

- `元数据状态：已观察`：固定只读元数据查询返回结构且与冻结资产的存储引擎声明一致；它不证明来源、市场或合约身份。
- `状态：已证明`：本任务不产生该状态，避免把结构观察误报为完整来源身份证明。
- `状态：拒绝`：输入指纹冲突、结构与冻结声明冲突、越权、权限拒绝或安全规则失败。
- `状态：无法判定`：元数据不可达、缺失、冲突未裁决、字段不完整或没有完整来源证据。
- `失败`、`未成熟`和`失效`在批次摘要中保留并计数；任何计数不守恒时不发布批次。

## 时间与研究边界

主研究尺度只能是4小时、8小时、24小时、48小时。15分钟和1小时只能作为事后结果观察窗口，不能升级为市场状态尺度、事件探测尺度或交易许可尺度。元数据快照时间只标记采集时点，不替代事件时间、到达时间或数据截止时间。

## 授权与安全

远端只允许白名单逻辑别名`ubuntu`，SSH使用无交互、密码关闭、键盘交互关闭、无PTY和无转发选项。数据库连接使用`mysql --no-defaults`、本地Unix套接字和固定`information_schema`查询；任何业务表正文、环境变量、凭据和写入均失败关闭。批次目录追加式发布且不可覆盖，历史批次只读保留。

## 解释边界

数据库表名、列名、共同服务目录、表引擎或结构相似性不得单独推导来源提供者、交易场所、市场类型、精确合约、三类时间、因果关系、预测优势、胜率、收益、研究准入或交易许可。BTC与ETH分别统计，不能跨标的补偿缺失。
