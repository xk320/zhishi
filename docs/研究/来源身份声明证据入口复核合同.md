# 来源身份声明证据入口复核合同

## 目的

本合同用于复核任务-000079之后仓库中实际存在的来源身份声明入口。入口为空、字段不完整或证据指纹不匹配时，结果保持`未登记`或`无法判定`，不通过路径、文件名、表名、共同目录或结构观察推断来源身份。

## 固定字段与状态

每个BTC、ETH候选成员固定检查九个字段：来源提供者、交易场所、市场类型、标的身份、精确合约、数据对象、Schema确切版本、授权边界和字段中文映射。入口状态只允许`未登记`、`入口不完整`或`已登记`；只有九字段声明、唯一证据定位、当前成员指纹、Schema/授权指纹和撤销事实全部匹配，才可在后续任务中进入身份证明复核，不能在本合同中直接形成交易许可。

## 复核输入

- 任务-000079最终不可变批次及其成员清单、配置、规则和执行器指纹。
- `config/数据/数据来源与资产身份.json`与`config/数据/来源身份声明补采.json`中的显式`身份声明`数组。
- 最新`main`中的任务合同、缺口台账和阶段1审计报告。

## 失败安全

当前两个声明配置的`身份声明`均为空时，630个成员分别记录为`未登记`；BTC和ETH各315个，不跨标的补偿，不缩小候选分母。历史批次只读保留，复核批次追加式且不可覆盖。结果只能说明入口事实和解除条件，不产生因果、预测优势、胜率、收益、研究准入或交易许可结论。

## 研究尺度边界

主研究尺度固定为4小时、8小时、24小时、48小时；15分钟、1小时只能作为事后结果观察窗口，不得升级为市场状态、事件探测或交易许可尺度。

## 解除条件

为每个成员提供当前版本九字段声明、唯一证据定位、证据文件和当前成员SHA-256、Schema指纹、授权快照及可撤销记录，随后按相同BTC/ETH分母生成新的不可变复核批次，并由阶段1最终审计重新裁决。
