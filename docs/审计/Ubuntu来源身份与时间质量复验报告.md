## 执行与资源事实

实际执行命令：

```bash
python3 scripts/数据/冻结数据来源身份.py \
  --contract config/数据/数据来源与资产身份.json \
  --ssh-target ubuntu \
  --batch-root artifacts/数据/来源身份 \
  --timeout 600

python3 scripts/数据/验证时间与质量合同.py \
  --contract artifacts/数据/时间质量合同/任务-000061输入/时间与质量规则.json \
  --identity-batch artifacts/数据/来源身份/source-identity-20260805T140150+0800-f310f869e6f2/身份清单.json \
  --task docs/研发中心/任务/任务-000061.md \
  --batch-root artifacts/数据/时间质量合同
```

- 来源身份入口执行时间约0.98秒；时间质量合同入口执行时间约0.16秒。
- 执行前本机磁盘可用约165 GiB，交换空间可用约739 MiB；未新增依赖。
- 来源身份探针仅使用逻辑别名`ubuntu`，远端无落盘、未读取数据库业务记录；时间质量入口只
  读取本地不可变来源身份清单和规则快照。
- 本批次没有测得独立峰值RSS，因此不声称峰值内存数值；脚本既有超时、成员数、输出和远端
  地址空间上限保持不变。
