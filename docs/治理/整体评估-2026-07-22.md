# 《知势》整体评估

- 评估日期：2026-07-22
- 评估范围：项目定位、术语、研究治理、系统架构、路线图、任务体系、风险边界
- 当前结论：**整体方向正确，无架构级阻塞；完成决策合同后进入数据闭环阶段。**

## 一、总体判断

《知势》已经完成从“行情分析工具”向“高质量交易许可系统”的关键收敛。

当前核心目标明确：

> 在 BTC、ETH、SOL 中，针对 4小时、8小时、24小时和48小时尺度，筛选最值得交易的唯一标的；没有充分优势时主动空仓。

项目已经建立以下正确边界：

- 不追求预测所有行情。
- 不强制每日交易。
- 不追求吃完整段涨幅。
- 复杂方法必须战胜简单基准。
- 风险层拥有一票否决权。
- 所有研究必须可证伪、可重放、可淘汰。
- 真实资金自动下单不属于第一阶段。

因此，项目可以继续推进，不需要重做顶层方向。

## 二、已经形成的优势

### 1. 目标收敛

第一阶段只覆盖 BTC、ETH、SOL，避免一开始扩展到大量山寨币和无法控制的叙事风险。

### 2. 时间尺度明确

4小时、8小时、24小时和48小时覆盖了短周期资金行为，同时避免进入毫秒级竞争。

### 3. 空仓被正式定义

项目没有把“无信号”视为系统失败，而是把空仓定义为正式决策。这与最高原则一致。

### 4. 决策与研究分离

系统蓝图已经区分数据、特征、市场状态、相关状态、资金轮动、机会评估、风险否决和交易许可，避免某一个指标直接决定交易。

### 5. 中文语言体系

《知势词典》已经明确用户可见指标、参数和状态使用中文，同时允许第三方原始字段保留英文，兼顾品牌一致性和工程兼容性。

### 6. 研究准入严格

研究必须包含基准、样本外、成本、失败样本和稳健性，能够有效阻止指标堆砌与回测过拟合。

## 三、评估中发现的关键缺口

### 1. 缺少正式决策合同

已有系统蓝图说明“有哪些层”，但尚未完整定义“所有质量门通过后才能允许交易”的统一合同。

处理：本阶段建立《知势决策标准》与统一决策卡。

### 2. 风险与仓位概念尚未完全分离

此前讨论过“200U 探测仓”和“高确定性最多 50% 仓位”，但绝对金额和资金占用不能替代最大允许损失。

处理：仓位改为由账户权益、风险比例、止损距离、成本和组合风险推导；50% 只作为资金占用上限。

### 3. 容易误用固定胜率门槛

“宁可错过，不做低胜率交易”不应被简化为未经验证的固定 70% 门槛。

处理：使用校准后的预测胜率、区间下界、盈亏平衡胜率和安全边际共同决定许可。

### 4. 每日收益目标可能诱发过度交易

“每天抓 1～2 次、每天获得较高账户收益”可以作为愿景讨论，但不能成为强制生产指标。

处理：系统优化单笔净期望、回撤、风险调整收益、空仓比例与违规次数，不设置强制每日收益。

### 5. Codex 自动执行尚缺仓库级约束

自动化代理需要知道当前阶段、不可越过的门槛、语言规范、安全边界和完成报告格式。

处理：新增根目录 `AGENTS.md` 和《任务与验收规范》。

### 6. 数据闭环尚未验证

当前最大实质风险不是模型，而是无法证明在任意历史时刻只使用当时已经到达的数据。

处理：`任务-000001` 继续作为进入基准研究的硬门槛。

## 四、项目风险清单

| 风险 | 严重度 | 当前控制 |
|---|---|---|
| 未来数据泄漏 | 极高 | 数据审计、事件时间与到达时间、可重放要求 |
| 回测过拟合 | 高 | 简单基准、样本外、滚动验证、参数敏感性 |
| 交易成本遗漏 | 高 | 成本门、净期望统一口径 |
| 确定性冒充胜率 | 高 | 决策合同强制分离 |
| 高杠杆放大随机误差 | 极高 | 权益风险驱动仓位、强平缓冲、风险否决 |
| 强制每日交易 | 高 | 默认空仓、频率与纪律门 |
| BTC/ETH/SOL 组合假分散 | 高 | 同方向相关风险合并计算 |
| 数据源中断 | 高 | 数据健康状态与自动禁止交易 |
| 复杂度失控 | 中 | 研究准入、阶段门槛、暂缓复杂模型 |
| 真实资金过早启用 | 极高 | 生产风险比例默认 0，真实交易许可关闭 |

## 六、推进决策

结论：

> 顶层目标、第一阶段边界和研究治理没有方向性问题，可以自动进入下一阶段。

执行顺序：

1. 合并决策合同、风险预算和 Codex 规范。
2. 持续执行并验收 `任务-000001` 数据资产审计。
3. 数据闭环通过后，建立无交易、买入持有、简单动量和简单相对强弱基准。
4. 基准稳定后，再研究市场状态、相关状态和资金轮动。
5. 所有复杂模型继续推迟。

## 七、当前唯一最高优先级

> **先证明我们能够在历史任意时刻知道“当时系统真实知道了什么”，再讨论系统能预测什么。**

在该能力通过验收前，任何漂亮的胜率、收益率或模型分数都不具备生产可信度。
