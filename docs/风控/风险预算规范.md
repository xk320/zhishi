# 《风险预算规范》V1

> 仓位不是信心表达，最大允许损失才是风险表达。

## 一、目的

本规范定义《知势》如何从账户权益、止损距离、交易成本和组合风险推导仓位。

第一阶段仅用于回测、模拟交易和影子决策。真实资金风险比例默认关闭，未经独立验收不得启用。

## 二、核心原则

1. 先定义最大允许损失，再计算仓位。
2. 杠杆不等于确定性。
3. 保证金金额不等于真实风险。
4. 高确定性可以影响风险预算的分档，但不能突破绝对风险上限。
5. “最高使用 50% 资金”是资金占用上限，不是单笔亏损上限。
6. BTC、ETH、SOL 同方向仓位必须按相关组合计算，不得视为三笔独立风险。
7. 失效条件无法定义时，仓位必须为 0。
8. 不使用马丁格尔，不因亏损扩大风险预算，不对失效仓位摊低成本。

## 三、核心参数

所有参数必须有中文名称、单位、来源、版本和适用环境。

| 参数 | 含义 | 单位 | 初始状态 |
|---|---|---:|---|
| 账户权益 | 当前可承担风险的净权益 | USDT | 实时输入 |
| 可用资金 | 扣除已占用保证金后的可用权益 | USDT | 实时输入 |
| 单笔风险比例 | 一笔交易允许损失占账户权益的比例 | % | 模拟参数；生产默认 0 |
| 单日风险比例 | 当日全部新交易允许损失上限 | % | 模拟参数；生产默认 0 |
| 组合风险比例 | 所有未平仓方向风险之和上限 | % | 模拟参数；生产默认 0 |
| 计划资金占用上限 | 单笔交易最多占用可用资金的比例 | % | 不高于 50%，具体值待验证 |
| 最大杠杆 | 执行层允许使用的杠杆上限 | 倍 | 待验证 |
| 止损距离 | 入场价到价格止损的相对距离 | % | 每笔计算 |
| 预估成本率 | 往返手续费、滑点和资金费率之和 | % | 每笔计算 |
| 风险缓冲率 | 应对跳价、延迟和估计误差的额外缓冲 | % | 待验证 |
| 强平缓冲率 | 止损价与强平价之间最低安全距离 | % | 待验证 |
| 当日已用风险 | 当日已实现和未实现风险占用 | USDT / % | 实时计算 |

“200U 探测仓”等绝对金额属于账户级配置，不属于通用核心模型。它仍然必须受单笔最大允许损失约束。

## 四、仓位计算

### 1. 单笔最大允许损失

```text
单笔最大允许损失
=
账户权益 × 单笔风险比例
```

若当日剩余风险预算更低，则使用较小值：

```text
本笔可用风险
=
min(
  单笔最大允许损失,
  单日风险上限 - 当日已用风险,
  组合风险上限 - 当前组合风险
)
```

本笔可用风险小于等于 0 时，禁止交易。

### 2. 有效损失率

```text
有效损失率
=
止损距离
+ 预估往返手续费率
+ 预估滑点率
+ 预估资金费率
+ 风险缓冲率
```

对于可能跳价的市场，不能假设一定按止损价成交。风险缓冲必须反映历史最差或保守执行结果。

### 3. 初始名义仓位

```text
初始名义仓位
=
本笔可用风险 ÷ 有效损失率
```

### 4. 资金占用约束

```text
最大允许保证金占用
=
可用资金 × 计划资金占用上限
```

```text
保证金约束后的名义仓位
=
最大允许保证金占用 × 计划杠杆
```

最终名义仓位取以下较小值：

```text
最终名义仓位
=
min(
  初始名义仓位,
  保证金约束后的名义仓位,
  市场流动性允许仓位,
  交易所限制仓位,
  组合风险允许仓位
)
```

### 5. 交易数量

```text
交易数量
=
最终名义仓位 ÷ 计划入场价格
```

必须按照交易所数量精度向下取整，并重新核算最大损失。

## 五、确定性与风险分档

确定性只能在已校准、已验证的风险档位之间选择，不能直接映射为任意仓位。

建议的逻辑结构：

| 风险档位 | 适用状态 | 风险预算处理 |
|---|---|---|
| 禁止 | 任一硬质量门失败 | 仓位 0 |
| 探测 | 研究证据有限，仅允许影子或小额验证 | 使用最低风险档 |
| 标准 | 样本外优势稳定，全部质量门通过 | 使用标准风险档 |
| 增强 | 多项独立证据一致且经过校准 | 可提高至增强风险档，但不得突破绝对上限 |

风险档位阈值和具体比例必须由回测与模拟交易确定。

未经校准的“确定性 90 分”不得自动触发 50% 资金占用。

## 六、组合风险

### 1. 相关方向合并

BTC、ETH、SOL 经常高度相关。以下仓位必须合并计算风险：

- 同时做多 BTC、ETH、SOL。
- 同时做空 BTC、ETH、SOL。
- 具有相同市场因子的跨标的仓位。

组合风险至少使用以下两种估计中的较大值：

- 各仓位价格止损损失之和。
- 历史压力场景下的组合损失。

### 2. 单一因子集中

即使交易三个标的，只要收益主要依赖“BTC继续上涨”这一共同假设，也视为单一风险因子。

系统必须保存：

- 标的风险。
- 方向风险。
- 共同市场因子风险。
- 交易所风险。
- 保证金模式风险。

### 3. 全仓与逐仓

风险模型不得把全仓账户的额外余额视为止损替代品。

第一阶段回测和模拟交易优先按独立仓位风险核算。使用全仓模式时，仍必须按预设止损和组合风险约束计算，而不是依赖更远的强平价格。

## 七、强平与执行缓冲

允许交易前必须满足：

- 价格止损应在强平价格之前触发。
- 止损与强平之间存在经压力测试验证的缓冲。
- 极端波动、流动性断层和系统延迟场景下，损失仍在可接受范围内。
- 无法可靠计算强平价格时，禁止使用杠杆仓位。

计划杠杆的选择顺序：

1. 先确定风险预算。
2. 再确定止损距离。
3. 计算名义仓位。
4. 最后选择满足保证金与强平缓冲的最低必要杠杆。

不得先决定使用 20 倍杠杆，再反推风险。

## 八、加仓、减仓和重新入场

### 加仓

只有在以下条件全部成立时才允许：

- 原交易许可仍有效。
- 新增证据经过独立质量门检查。
- 加仓后的总风险未超限。
- 加仓不是为了摊低亏损成本。
- 加仓有新的失效条件和退出计划。

浮盈不等于“免费保证金”。使用浮盈加仓仍然必须重新计算组合最大损失。

### 减仓

以下情况可以触发减仓：

- 风险预算下降。
- 主要反证增强。
- 流动性恶化。
- 相关风险突然上升。
- 价格已完成大部分目标波动，剩余赔率不足。

### 重新入场

平仓后重新入场必须生成新的决策编号，不得沿用旧交易许可。

错过上涨、卖飞或上一笔盈利都不能构成重新入场依据。

## 九、单日和连续亏损保护

系统必须配置并验证：

- 单日最大新开仓次数。
- 单日最大允许亏损。
- 连续亏损暂停条件。
- 数据异常暂停条件。
- 模型校准失效暂停条件。

触发暂停后：

- 当日交易许可全部降级为禁止；或
- 进入预设冷静期，重新完成数据和模型健康检查。

暂停规则不能因“下一笔看起来很好”被人工临时绕过。

## 十、目标收益的正确表达

《知势》不设置“每天必须赚 5%～20%”的生产目标。

原因：

- 市场并非每天提供同等质量机会。
- 强制收益目标会诱发低质量交易、过度杠杆和追回亏损。
- 账户收益受到仓位、杠杆、成本和随机性的共同影响。

系统真正优化：

- 计入成本后的单笔净期望。
- 最大回撤。
- 风险调整收益。
- 空仓比例。
- 决策校准。
- 违规交易数量。

“捕捉 1% 左右价格波动”只是研究方向，必须根据波动环境动态调整，并与账户收益目标分开。

## 十二、默认安全状态

- 真实资金单笔风险比例：0。
- 真实资金交易许可：关闭。
- 缺少账户权益、止损或成本数据：仓位 0。
- 风险参数版本不明：仓位 0。
- 风险计算异常：仓位 0。

只有在事件驱动回测、模拟交易、影子决策和独立风险验收依次通过后，才允许另行制定真实资金启用规范。
