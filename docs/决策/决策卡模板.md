# 《知势决策卡模板》V1

本模板是《知势》所有模拟决策、影子决策和未来生产决策的统一输出格式。

原则：

- 任何必要字段缺失，交易许可自动为“禁止”。
- 禁止交易也必须输出完整理由，不能返回空结果。
- “确定性”不得代替“预测胜率”。
- 所有数字必须注明单位、时间尺度、数据截止时间和版本。
- 委员会评议报告必须与决策卡使用同一决策编号、数据版本和规则版本。

## 二、允许交易示例结构

以下仅说明结构，不代表真实参数或交易建议。

```text
交易许可：允许
首选标的：ETH
交易方向：做多
目标时间尺度：8小时

允许原因：
- 七道质量门全部通过。
- 预测胜率保守下界高于盈亏平衡胜率与安全边际之和。
- ETH 相对 BTC、SOL 的优势在样本外同类状态中稳定。
- 目标波动能够覆盖手续费、滑点、资金费率和安全余量。

建议仓位：由风险预算公式计算
单笔最大允许损失：由账户权益与单笔风险比例计算
逻辑失效条件：必须与入场假设直接相关
最长持有时间：8小时
```

## 三、禁止交易示例结构

```text
交易许可：禁止
首选标的：无
交易方向：无
建议仓位：0

否决质量门：优势门、样本门
否决原因：
- BTC、ETH、SOL 的排名差异不足。
- 当前低相关状态样本数量不足，预测胜率无法可靠校准。
- 主要支持证据与反证冲突。

允许重新评估的条件：
- 数据质量恢复；或
- 形成新的完整 4 小时周期；或
- 相对强度差异达到已验证门槛；或
- 当前市场状态进入已验证范围。
```

## 五、复盘追加字段

交易窗口结束后，在同一决策记录中追加：

```text

净收益：
是否遵守计划：
决策过程评价：正确 / 有缺陷 / 违规
结果评价：盈利 / 亏损 / 持平 / 未执行
```

一次盈利不能证明决策正确，一次亏损也不能自动证明决策错误。过程与结果必须分别评价。
