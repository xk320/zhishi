# 任务-000101设计：任务-000100冻结输出合同修复可信通道

<!-- markdownlint-disable MD013 -->

## 决策

采用固定两步治理路线：

1. 任务-000101只在main可信规则中建立任务-000102到任务-000100的一次性精确映射；
2. 任务-000102只替换任务-000100固定输出合同和直接对应验收文字。

不在引导PR修改目标任务，不建立通用合同编辑器。

## 冲突与裁决

任务-000100要求更新两个被旧任务按字节冻结的历史文件。直接更新会破坏历史证据；
完全不更新又违反输出合同。裁决为保留历史文件，改由独立追加报告承载当前证据，并通过
固定合同修复明确这一替代关系。

## 可信边界

- 固定执行任务：任务-000102；
- 固定目标任务：任务-000100；
- 固定目标状态：修复PR的基线和头部均为待执行；
- 固定允许变化：只替换合同逐字指定的一个输出条目；验收标准不修改；
- 固定授权顺序：任务-000102先完成并进入main，随后由独立目标修复PR使用授权；不在目标修复PR迁移源任务状态；
- 固定禁止路径：两个历史审计文件、旧配置、旧批次和原始数据；
- 任何其他变化失败关闭。

## 验证

治理测试必须覆盖成功完整替换，以及未知任务、未知目标、部分替换、状态迁移、额外合同
改写、历史文件夹带和生产/数据路径的失败关闭。
