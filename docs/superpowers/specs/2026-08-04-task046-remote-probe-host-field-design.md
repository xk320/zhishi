# 任务-000046设计：远端探针字段常量自包含

## 设计结论

远端探针是通过标准输入在清洁空命名空间执行的独立程序，不能依赖宿主模块的全局常量。
在探针代码自身定义`HOST_FIELD = "h" + "ost"`，保留脱敏字段名而不引入凭据或网络目标，
使`payload`构造在所有本地模拟场景和真实只读执行边界下拥有确定行为。

## 回归矩阵

| 场景 | 预期 |
| --- | --- |
| 正常只读探针 | 输出结构化payload |
| 命令缺失 | 输出错误记录，不抛未定义名称 |
| 目录遍历候选文件 | 输出过滤后的文件事实 |
| 目录权限错误 | 输出部分不可访问错误事实 |

不改变命令白名单、目录白名单、敏感字段脱敏、BTC/ETH当前范围或远端写入禁止。
