# 任务-000079：来源身份声明与当前证据补采设计合同

## 目标

建立显式、版本化、内容寻址的来源身份声明及证据定位格式，补采当前BTC、ETH候选成员的身份、Schema和授权摘要。任何无法逐字段证明的成员均保持`无法判定`，不得用路径或名称推断。

## 固定边界

- 仅覆盖BTC、ETH；主研究尺度为4小时、8小时、24小时、48小时。
- 15分钟、1小时只能作为事后结果观察窗口，不能升级为状态、事件或许可尺度。
- 仅使用仓库合同、不可变批次和Ubuntu白名单无交互只读摘要；不读取市场业务正文、凭据或生产数据。
- 不修改历史批次、生产服务、数据库权限或原始数据，不生成交易结论。

## 证据模型

每条声明绑定：任务/合同版本、资产编号、标的、当前输入成员SHA-256、身份字段、声明值、证据来源路径或脱敏远端摘要指纹、证据文件SHA-256、Schema/授权指纹、采集时间和撤销事实。缺少任一绑定时只能输出`无法判定`。

## 批次与失败安全

批次目录在同一父目录临时生成，完成校验后以原子无覆盖方式发布；同名目录、输入漂移、越权、敏感输出、超时、状态不守恒和未来数据均拒绝发布。BTC/ETH独立计数，不跨标的补偿。结果仅精确更新`ZS-DATA-GAP-001`，不得改变阶段门或其他缺口。

## 可复现验证

专项测试验证字段集合、声明与证据匹配、成员排序、状态守恒、敏感输出拒绝、原子发布和历史批次不变；完整数据、审计、研发中心、编译、MarkdownLint及差异检查由任务合同执行。

## 完成边界

本设计不代表任何成员已证明，不代表阶段1或阶段2放行。若远端没有足够声明证据，任务仍可交付失败安全批次并明确解除条件。
