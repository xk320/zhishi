# 任务-000112：资格工作流合并事实同步设计

## 目标

让PR资格检查工作流与自动合并工作流使用同一份可信关联合并事实元数据，确保压缩合并状态闭环在资格阶段即可复算。

## 边界

- 只修改资格工作流、任务合同、测试和看板；不访问业务服务器、数据库、原始数据、凭据或生产服务。
- 复用任务-000111已合并的压缩合并校验规则，不新增事实类型或放宽安全门。
- 无关联合并事实、字段不完整或API失败时保持失败关闭。

## 交付与验收

- 资格工作流读取并绑定PR正文中的关联合并事实PR元数据。
- 现有自动合并工作流与双父/单父测试保持通过；任务-000110状态闭环资格可复算。
