# 任务-000109：数据缺失审计替代路线设计

## 目标

停止对已由采集架构固定的Binance来源做重复供应商身份审计，改为只读取现有脱敏批次，回答正式研究输入在哪里缺失、缺失多少、影响哪些标的和尺度。

## 设计约束

- 任务-000084旧来源身份合同和历史批次保持不可变，仅由任务-000109建立替代关系。
- 只读仓库内已合并批次，不访问服务器、数据库、网络、原始市场数据、账户或凭据。
- 只统计缺失、拒绝、无法判定、未成熟、失效和连续覆盖段，不把来源标签当作新的研究证据。
- BTC、ETH、数据对象和4/8/24/48小时尺度独立裁决；15分钟、1小时仅为事后结果窗口。

## 输出

- 缺失审计合同和固定配置；
- 可复算的缺失成员、日期、区间和叶子摘要；
- 任务-000084替代关系和后续取消依据；
- 不新增运行时交易能力，不改变阶段2和真实资金关闭状态。

## 验收

输入、规则、执行器和输出指纹可复算；状态和缺失计数守恒；历史来源身份批次不变；专项测试、MarkdownLint和`git diff --check`通过。
