# 任务-000052：有证据取消状态闭环设计

## 设计目的

补齐任务规范中已经声明、但可信自动合并规则尚未实现的`已取消`终止迁移，用可复算证据
裁决任务-000050与任务-000051的重复交付关系，避免永久阻塞或伪造完成。

## 设计决策

- `已取消`只接受未完成状态迁移，且一次状态闭环最多处理一个任务；已完成任务永不取消。
- 取消记录必须绑定取消原因、替代任务、替代PR和已进入`main`的替代合并提交SHA；Git提交主题
  和祖先关系由可信规则复验，Issue和聊天不具备事实权威。
- 取消看板证据从任务文件字段确定性生成，禁止手工写入不一致行；取消不自动解除依赖或改变研究范围。
- 任务-000050的裁决只引用任务-000051已合并PR #89及PR #86失败关闭事实，不把任务-000050伪造为已执行。

## 安全与回滚

证据缺失、提交未进入基线、状态或合同漂移均失败关闭；回滚取消闭环提交即可恢复任务-000050
阻塞状态和原看板，不删除任务文件、不触碰服务器、数据库、原始数据、账户或生产服务。
