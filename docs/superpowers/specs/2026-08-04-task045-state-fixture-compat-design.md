# 任务-000045设计：状态闭环测试双态夹具兼容

## 设计结论

任务-000045只修复测试夹具与真实任务状态之间的兼容性，不改变任务状态机、看板模式、
可信资格校验器或任何外部事实。测试读取任务-000043当前状态：若为`待评审`，在内存中
移除待评审行并把完成行插入“已完成”章节；若为`已完成`，在内存中移除完成行并把待评审
行插入“待评审”章节。每个夹具都经过同一章节感知断言。

## 必须覆盖

- 合法状态：`待评审`、`已完成`；
- 状态与看板章节一一对应；
- 错分区、缺失行、未知状态、缺失状态和重复状态失败；
- 历史任务记录缺失失败；
- 现行四态外部状态、新鲜度和唯一恢复路径不回退。

## 安全与回滚

夹具只在内存中生成，不写入任何任务文件或外部数据。回滚仅需回滚本任务测试提交，
不触碰任务-000043真实状态和PR #62合并事实。
