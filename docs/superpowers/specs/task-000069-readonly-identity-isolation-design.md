# 任务-000069设计：阶段1数据证据复采的专用远程只读身份

<!-- markdownlint-disable MD013 -->

## 决策

先建立独立SSH身份和强制命令边界，再允许后继任务按各自合同读取数据证据。root只能做一次性账户管理，不能成为数据读取身份。

## 威胁与边界

- root会话误被复用于业务读取；通过任务合同、固定命令和执行记录阻断。
- 专用账户获得sudo或转发能力；通过UID、组、密钥选项和负向探针验证。
- 私钥、地址、用户名、原始记录进入仓库；通过本地密钥指纹、脱敏字段白名单和敏感扫描阻断。
- 身份验证被误解释为数据或交易许可；报告明确只证明身份隔离，不改变阶段门禁。

## 固定身份模型

专用账户使用单一公钥、锁定密码、非管理员组和SSH密钥强制命令`/usr/bin/python3 -`。密钥使用`restrict`选项，禁止PTY、代理转发、端口转发和X11转发。账户只接受后继任务批准的标准输入探针，不提供任意远程命令。

## 证据模型

批次只保存账户/密钥/组权限/强制命令的内容指纹、退出码、资源和状态；不保存账户名称、主机地址、密钥正文、凭据、原始日志或业务字段。每个探针结果有确定性成员顺序，批次追加且不可覆盖。

## 解除条件

身份和权限隔离批次通过后，才允许登记后继的数据证据复采任务。任何权限漂移、敏感输出、越权命令、资源超限或根身份读取都会使本任务失败关闭并保持阶段1阻塞。

## 不实施

本设计不授予数据库写权限，不执行数据复采，不修改订单簿或生产服务，不训练模型、不回测、不模拟交易、不生成胜率收益或交易许可。
