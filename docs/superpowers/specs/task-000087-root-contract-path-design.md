# 任务-000087设计：阻塞合同修复目标路径解析

## 问题

受控阻塞合同修复的PR正文只应声明执行任务，例如任务-000086；目标任务-000084通过固定映射确定。现有CLI还从变更路径加入任务编号，造成执行任务集合包含目标任务，合法修复被多任务引用硬门拒绝。

## 设计

- `task_ids`只保留PR正文引用的执行任务。
- 对任务-000056→任务-000055和任务-000086→任务-000084，按固定映射把目标任务加入`load_ids`，仅用于加载base/head正文和合同指纹比较。
- 目标任务仍不属于PR引用任务；允许目标任务文件只在固定映射返回的受控未引用集合中出现。
- 其他变更类型保持原有从任务路径推导和未引用任务失败规则。

## 安全保证

未知执行任务、错误目标、额外任务文件、策略/看板路径、状态迁移、段落漂移和合同越权均失败关闭。该修复不改变root段落、自动合并范围、任务状态、数据访问或服务器权限。

## 验证

使用合成Git路径事实覆盖合法root目标、旧映射、未知目标、额外任务路径和普通交付回归；运行研发中心全量测试、MarkdownLint、Python编译和差异检查。
