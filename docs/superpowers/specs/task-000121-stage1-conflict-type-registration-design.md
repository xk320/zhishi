# 任务-000121：阶段1合同修订跨载体类型识别设计

## 目的

修复可信跨载体冲突检查器未识别已批准变更类型`阶段1覆盖受限合同修订`的问题，使任务-000115后续受控修订可以由现有主可信资格器继续执行，而不放宽任何任务合同、路径或安全边界。

## 固定边界

- 仅登记固定中文变更类型、任务-000115→任务-000106映射和对应失败关闭测试。
- 不改变任务-000115、任务-000106、任务-000116的合同、状态、看板或历史证据。
- 不改变普通交付、状态闭环、任务登记和既有合同修复语义。
- 不访问服务器、数据库、市场数据、凭据、生产服务或真实交易路径。

## 预期结果

跨载体检查器能够识别该类型，并只在任务-000115、目标任务-000106、固定路径和可信资格器已经约束的状态下跳过重复的通用合同漂移冲突；未知类型、错任务、错目标、额外路径和元数据漂移继续失败关闭。

## 验证

运行跨载体冲突专项测试、研发中心资格专项测试、Python编译、MarkdownLint和`git diff --check`，所有结果如实记录在任务交付PR中。
