# 任务-000114：固定 root 兼容模式的阻塞基线测试夹具

## 目的

任务-000084已取消后，任务-000086 root兼容模式的历史正向测试不能再读取当前任务文件推导“阻塞”状态。本设计固定一个显式合成阻塞合同夹具，避免测试依赖已取消任务。

## 方案与边界

- 仅修改研发中心测试夹具及其任务记录。
- 合成夹具只用于验证既有失败安全路径，不代表真实任务状态。
- 不修改可信校验规则、任务084/086合同、历史批次、服务器、数据库、生产或交易系统。

## 验收

- 正向 root兼容测试使用显式阻塞基线并通过。
- 已取消目标负向测试保持失败关闭。
- 相关研发中心测试、编译、MarkdownLint和diff检查通过。
