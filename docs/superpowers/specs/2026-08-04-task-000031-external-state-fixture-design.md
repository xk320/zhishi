# 任务-000054：任务-000031外部状态一致性测试夹具设计

## 问题

任务-000031在外部环境恢复后从“阻塞”合法迁移为“待执行”，但外部状态一致性测试仍
固定断言历史“阻塞”状态，导致真实状态闭环后研发中心全量回归失败。

## 设计

- 以任务文件状态和看板机器合同为输入，分别覆盖“阻塞”和“待执行”两种合法基线；
- “阻塞”基线继续校验脱敏阻塞原因、阻塞链和唯一看板行；
- “待执行”基线校验解除字段、唯一前序依赖和待执行看板表格；
- 任一未知状态、错分区、缺失行、重复行或任务链漂移继续失败。

## 不变边界

设计只影响测试夹具，不改变任务状态迁移资格、不读取服务器或市场数据、不修改历史证据，
也不扩大BTC/ETH研究范围或自动合并权限。

## 验证

使用任务-000054合同中的专项测试、研发中心全量测试、脚本编译、Markdown lint和差异检查。
