# 任务-000080：来源身份声明证据入口复核设计合同

## 目标

在任务-000079建立的声明与证据格式上，复核仓库中实际存在的来源身份声明入口和逐字段证据可见性。入口为空、证据缺字段或指纹不匹配时，保留`无法判定`，不以路径、名称、表名或结构观察推断身份。

## 固定边界

- 仅覆盖BTC、ETH及4小时、8小时、24小时、48小时主研究尺度；15分钟、1小时仅为事后结果观察窗口。
- 默认仅读取仓库合同、不可变批次和已登记结构化证据，不访问业务正文、价格、成交、订单簿、账户或凭据。
- 不修改历史批次、原始数据、数据库、生产服务、权限或账户，不生成交易结论。

## 复核模型

每个候选成员固定检查九个身份字段：来源提供者、交易场所、市场类型、标的身份、精确合约、数据对象、Schema确切版本、授权边界和字段中文映射。每个字段必须绑定声明来源、唯一定位、证据文件指纹、当前成员SHA-256、Schema/授权指纹和撤销事实；任一字段缺失即不能成为已证明成员。

## 失败安全与批次

批次必须追加式、原子发布、不可覆盖历史目录。入口为空、输入漂移、敏感输出、越界、未来数据、状态不守恒或跨标的补偿均失败关闭；BTC和ETH分别统计。复核结果只精确更新`ZS-DATA-GAP-001`，不能关闭其他缺口或阶段门。

## 完成边界

本设计不预设任何身份字段存在，也不承诺形成已证明成员。完成只表示入口事实、缺失原因、解除条件和可复算批次已记录；阶段1/阶段2仍需最终审计裁决。
