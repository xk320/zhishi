# 任务-000083：来源身份候选表只读接入与九字段复验设计

<!-- markdownlint-disable MD013 -->

## 目标

在任务-000082已冻结的空入口事实基础上，使用已批准的专用只读身份，发现并复验共享数据库中可能承载结构化来源身份声明的候选`BASE TABLE`。只有完整九字段、成员绑定、Schema/授权指纹和可撤销事实全部可复算时，成员才可标记为`已证明`。

本设计不把表名、列名、目录、结构相似性或行数解释为来源身份；候选不存在或字段不完整时，必须保留`未登记`、`无法判定`或失败安全状态。

## 固定研究边界

- 标的仅为BTC、ETH，分别统计，不跨标的补偿。
- 主研究尺度固定为4小时、8小时、24小时、48小时。
- 15分钟、1小时只作为事后结果观察窗口，不得升级为市场状态、事件探测或交易许可尺度。

## 证据与状态

- 候选总体、分母、已观察、拒绝、无法判定、失败、未成熟和失效必须按BTC、ETH分别守恒。
- 完整九字段和全部指纹匹配才允许`已证明`；仅元数据可见、结构匹配或表存在不得升级状态。
- 结果可见后不得更换分类、筛选事件、修改分组、缩小分母或寻找最佳状态、事件或窗口。
- 描述性差异不得解释为因果、预测优势、胜率、收益、研究准入或交易许可。
- 批次追加式、不可覆盖；输出仅保存脱敏值、SHA-256、状态、原因、定位和资源事实。

## 远端与数据库边界

- 仅允许逻辑别名`ubuntu`和已批准的专用只读身份。
- 仅允许固定白名单根目录和共享数据库的`information_schema`元数据；候选对象通过严格签名后才可读取声明列。
- 只读声明列，不读取价格、成交、订单簿、持仓、账户、环境变量、凭据或其他业务正文。
- 禁止INSERT、UPDATE、DELETE、DDL、权限变更、远端临时写入、原始数据修改、生产服务修改和订单簿逻辑修改。
- 单批次串行、有界、可中止；任何越界、敏感输出、超时、指纹漂移或计数不守恒立即失败关闭。

## 输出

- 候选表白名单、逻辑字段映射和Schema指纹；
- BTC/ETH独立成员复验清单与不可变批次；
- `ZS-DATA-GAP-001`精确更新及阶段1影响；
- 不保存原始声明正文、凭据或业务数据。

## 通过条件

设计只在以下条件同时满足时允许进入执行：任务-000082已在最新`main`，只读权限可从固定入口复验，输入成员顺序可复算，候选表字段映射可冻结，且全部验证命令通过。没有候选或证据不足是可接受的失败安全结果，不得伪造成阶段1通过。
