# 来源身份声明入口发现与冻结合同

<!-- markdownlint-disable MD013 -->

## 一、目的

本合同定义任务-000082如何在已批准的白名单范围内发现、验证并冻结当前版本的来源身份声明入口。它只为
`ZS-DATA-GAP-001`补齐可验证的来源、市场、标的、合约和授权证据，不把路径、文件名、表名、目录归属、
服务名称或结构相似性直接解释为身份结论。

任务只处理BTC、ETH；主研究尺度固定为4小时、8小时、24小时、48小时，15分钟和1小时只能作为事后结果
观察窗口。任务完成不等于阶段1或阶段2放行。

## 二、身份声明最小合同

每个成员的声明必须同时绑定以下九个字段：

1. 来源提供者；
2. 交易场所；
3. 市场类型；
4. 标的身份；
5. 精确合约；
6. 数据对象；
7. Schema确切版本；
8. 授权边界；
9. 字段中文映射。

声明还必须绑定任务合同版本、成员编号、资产编号、当前输入成员SHA-256、声明入口的唯一定位、声明
内容SHA-256、Schema指纹、授权快照指纹、采集时间和可撤销事实。任一绑定缺失、冲突、漂移、过期或无法
重放时，成员只能为`无法判定`、`拒绝`或`失败`，不得降级门槛。

## 三、允许的声明入口

入口必须来自以下已冻结边界之一：

1. 仓库中的结构化声明配置：`config/数据/数据来源与资产身份.json`和
   `config/数据/来源身份声明补采.json`；
2. 逻辑别名`ubuntu`上既有白名单根目录中的、文件名完全匹配
   `来源身份声明.json`、`source-identity.json`、`data-source-manifest.json`或
   `dataset-identity.json`的普通文件。根目录只能取
   `config/数据/数据来源与资产身份.json`的`允许文件根目录`，不递归进入隐藏目录、密钥目录、运行时目录
   或未登记路径；单文件最多256KiB，只读读取内容并在敏感扫描失败时丢弃，不落盘原始内容；
3. 对任务-000081已冻结的数据库元数据成员，逻辑别名`ubuntu`上的固定只读
   `information_schema.TABLES`和`information_schema.COLUMNS`元数据。只允许读取数据库、Schema、表、
   表注释、列名、列类型、列顺序和列注释的摘要；不得读取业务表、价格、成交、订单簿、账户、环境变量或
   凭据。注释只有在显式声明九字段且能与当前成员逐项绑定时才可作为候选证据，空注释或描述性注释只能为
   `无法判定`。

数据库注释候选必须使用固定前缀`知势身份声明:`，前缀之后只能是UTF-8 JSON对象；对象的字段集合、九字段值、
成员编号、资产编号、声明版本、声明内容SHA-256、Schema指纹、授权快照SHA-256、撤销事实和证据定位均须通过
本任务的严格校验。表注释和列注释只返回脱敏摘要及显式声明对象，不返回业务记录或未声明的原始注释。

入口发现必须使用固定的文件名、列白名单、排序和资源上限；不得通过猜测路径、模糊匹配、目录名称或聊天
内容扩大入口。

## 四、状态与统计

每个BTC、ETH成员都必须保留候选总体、入口状态、可定位状态、最终身份状态、原因代码、证据定位、输入/规则/
执行器指纹、授权快照指纹和撤销事实。最终状态只能为`已证明`、`拒绝`、`无法判定`、`失败`、`未成熟`或
`失效`；入口状态只能为`未登记`、`入口不完整`或`已登记`。

BTC和ETH分别统计，成员顺序固定为`标的、资产编号、成员编号`升序；任何状态计数必须守恒，不得跨标的
补偿、删除未知成员、缩小分母或在结果可见后改变分类。

## 五、批次与安全

批次采用追加式、原子、不可覆盖目录，绑定输入快照、入口清单、规则指纹、执行器指纹、授权快照、资源事实、
逐成员结果和撤销事实。原始响应、凭据、地址、用户名、环境变量和业务字段不得写入批次。

资源上限：单进程、总超时600秒、单成员5秒、最多1000个成员、远端日志32KiB、远端输出8MiB、单文件读取
256KiB、本机Node堆256MiB；最多两个只读评审者，不创建额外工作树。

出现越权、敏感输出、写入、输入漂移、计数不守恒、历史目录存在、未来数据或无法复算时，立即失败关闭并
保留脱敏事实；不得通过更换入口、补造声明或修改原始数据继续运行。

## 六、解除条件与结论边界

只有BTC、ETH每个纳入成员均具有当前版本九字段声明、唯一定位、内容/成员/Schema/授权指纹和可撤销事实，
并能由不可变批次重放时，才可对精确成员范围部分解除`ZS-DATA-GAP-001`。结果为空或证据不足时，必须保留
`未登记`/`无法判定`并进入阻塞，不得宣称来源身份、数据质量、因果关系、预测优势、胜率、收益、研究准入
或交易许可。

本合同不授权服务器写入、数据库写入、权限变更、原始数据迁移、模型、回测、模拟交易或真实交易。
