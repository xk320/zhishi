# 任务-000056设计：治理任务测试路径授权冲突修复

## 设计结论

仅为任务-000055增加显式的`自动合并范围：治理自动化`合同字段，使其已批准的研发中心机器测试
交付可以进入受控路径；不修改全局白名单、不修改可信脚本、不修改任务目标和安全边界。

## 事实依据

PR #111的候选头包含任务-000055合同要求的机器负向测试，main可信资格返回测试路径不允许；
PR #112已将任务-000055如实标记为阻塞并记录可复现拒绝证据。授权修复合并后，任务-000055必须
从最新main独立恢复并重新执行。

## 失败安全

授权只作用于任务-000055合同声明的治理自动化范围；任何生产、服务器、真实数据、凭据、交易路径
或其他任务的自动合并资格仍保持拒绝。
