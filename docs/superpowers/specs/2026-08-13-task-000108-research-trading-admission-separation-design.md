# 任务-000108设计：研究准入与真实交易准入分离

## 冻结决策

第一阶段采用三层合同模型：

```text
阶段1数据证据门
        ↓（仅提供必要输入）
研究准入（研究范围与生命周期）
        ↓（仍不能下单）
单次交易许可（冻结决策上下文上的允许/禁止）
        ↓（仍不能接入真实资金）
真实交易准入（系统级真实资金能力：当前关闭）
```

三个对象不共享状态字段，不允许由上游结果自动生成下游允许状态。

## 三层职责

| 层 | 回答的问题 | 允许输出 | 明确不输出 |
| --- | --- | --- | --- |
| 阶段1数据证据门 | 数据是否具备指定时间、质量、来源、重放和成本/执行证据 | 数据门状态、缺口、适用范围 | 研究结论、交易许可、真实交易准入 |
| 研究准入 | 某个冻结研究版本是否可在限定范围内继续研究 | 研究生命周期状态、允许研究范围、淘汰/失效原因 | 单次交易许可、真实交易准入 |
| 单次交易许可 | 一个冻结决策上下文是否满足七道质量门 | `交易许可：允许/禁止`、仓位上限或0、否决原因 | 研究准入、系统级真实交易准入 |
| 真实交易准入 | 系统是否具备使用真实资金的独立资格 | `关闭/申请中/已批准/暂停/撤销` | 具体交易方向、仓位或订单 |

## 固定不变量

1. `研究准入：已纳入`不是`交易许可：允许`。
2. `交易许可：允许`不是`真实交易准入：已批准`。
3. 阶段1数据门通过不自动将研究版本升级为`已纳入`。
4. 任一层输入缺失、冲突、过期或无法判定时，该层保持保守状态；不得读取其他层缓存补齐。
5. 真实交易准入当前固定为`关闭`；本阶段任何研究、模拟、影子决策和历史重放都不能改变它。
6. 真实交易准入是能力门，不是交易信号，也不替代单次交易许可。

## 状态边界

### 研究准入

沿用《研究准入规范》的研究生命周期：`提议`、`验证中`、`候选`、`试运行`、`已纳入`、`已淘汰`、`已失效`。其中`试运行`只能用于模拟或影子决策，`已纳入`只能表示研究证据和治理评审完成，仍需重新满足单次交易许可和真实交易准入。

### 单次交易许可

沿用《交易许可协议》的二元输出：`允许`或`禁止`。缺失、冲突、超时、版本不一致、七道质量门任一失败或真实交易准入不是`已批准`时，最终结果为`禁止`，建议仓位为0。历史许可不可变，条件变化必须创建新决策编号。

### 真实交易准入

状态仅允许：

| 状态 | 含义 | 当前是否允许真实资金 |
| --- | --- | --- |
| `关闭` | 未建立或未满足独立启用合同 | 否 |
| `申请中` | 正在收集独立启用证据，尚未形成批准 | 否 |
| `已批准` | 独立启用评审、权限、风控、执行、监控和回滚证据全部满足 | 仅表示能力门通过，仍须逐笔交易许可 |
| `暂停` | 已批准能力被风险、数据、执行或监控事件临时冻结 | 否 |
| `撤销` | 既有批准被永久取消，必须重新申请 | 否 |

状态转换必须生成独立版本化记录。任何状态缺失或冲突均降级为`关闭`；禁止从研究准入或交易许可直接跳转到`已批准`。

## 第一阶段映射

阶段1只负责数据证据门和允许研究范围的上界。当前任务-000105的结论仍是阶段1未完成、阶段2禁止，因而预测性研究范围为空；任务-000106的多年成本与真实执行延迟缺口继续按原合同阻塞。本设计不改变这些事实。

在未来阶段1数据门完整通过时，最多只能使某些研究版本获得重新申请研究准入的资格；仍必须单独完成研究准入、单次交易许可和真实交易准入。真实资金状态在本任务完成后仍为`关闭`。

## 不在本设计内

- 不定义真实交易准入的具体生产阈值、账户权限、凭据、服务器部署或订单接口。
- 不补充市场数据，不训练模型，不回测，不生成方向、仓位、订单、胜率或收益。
- 不把模拟/影子结果、阶段1数据证据或研究`已纳入`状态解释为真实交易授权。
- 不新增交易许可质量门，不改变《知势宣言》“宁可错过，不做低胜率交易”的风险纪律。
