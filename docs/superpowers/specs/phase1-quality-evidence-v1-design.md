# 阶段1数据对象质量与完整扫描复验设计

<!-- markdownlint-disable MD013 -->

本设计对应任务-000062，绑定任务-000061形成的来源身份和时间质量批次，在不覆盖历史证据的
前提下重新执行一次有界的只读质量审计。

## 设计约束

- 输入成员集合、BTC/ETH边界、4小时/8小时/24小时/48小时主尺度和15分钟/1小时观察窗口必须
  与任务-000061精确一致。
- 只使用既有持续验证脚本和底层审计器；不另建扫描器，不读取数据库业务正文，不修改原始数据。
- 质量、断档、异常、完整扫描和元数据范围分别保留已知和未知状态；未知不填零。
- 新批次使用独立目录和追加索引，任何规则、清单、Schema或输入变化都触发不可比较的新批次。

## 证据绑定

报告必须同时给出来源身份、时间质量、资产清单、方案、规则、审计器、作用域和成员顺序指纹，
并说明这些指纹与任务-000061的关系。若成员集合或指纹不一致，任务必须失败安全，不得用旧
批次补齐新批次。

## 阶段门影响

本任务最多只提供数据质量硬门的新增证据，不自动解锁重放、成本、血缘、容量、恢复或阶段2。
任何局部通过必须精确限定到标的、场所、合约、对象、尺度和时间范围；未被完整证据覆盖的范围继续阻塞。
