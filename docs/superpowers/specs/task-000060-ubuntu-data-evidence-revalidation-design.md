# 任务-000060设计：Ubuntu 数据证据增量复验

## 目标

在任务-000031已有证据之后，使用最新 `main`、相同白名单和新的冻结输入，形成一个不可覆盖、
可复算的 Ubuntu 只读数据证据批次。新批次只表达数据与质量证据状态，不改变阶段门或交易许可。

## 固定方案

方案A“复用既有只读审计器的增量批次复验”。复用
`scripts/审计/持续验证数据质量.py`及现有任务-000031配置，先冻结清单、规则、资源上限和
数据截止信息，再通过逻辑别名 `ubuntu` 执行白名单只读探针；失败或未知保持原状态，不补造结论。

## 研究范围

- 前向标的仅 BTC、ETH，分别统计、不得互相补偿。
- 主研究尺度仅4小时、8小时、24小时、48小时。
- 15分钟、1小时只能作为事后结果观察窗口，不得成为状态尺度、事件尺度或交易许可尺度。

## 安全与回滚

远端仅允许现有合同批准的只读路径、文件元数据/内容规则和数据库元数据读取；禁止远端落盘、
原始数据修改、生产写入、权限变更、凭据读取、模型、回测和交易。新批次按唯一批次目录追加，
回滚只删除本PR新增的文档/聚合证据，不触碰历史批次。
