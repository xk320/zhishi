# 任务-000058：阻塞任务合同证据对齐设计

## 问题

任务-000056的现有合同已经在固定方案、输入合同和输出合同中明确任务-000055是唯一目标，
但任务-000057资格器要求额外的固定措辞“任务-000055当前阻塞合同”。该措辞不在已合并
合同中，造成规则与事实来源冲突并使PR #127失败关闭。

## 设计

资格器继续要求三类独立证据：

1. 输出合同包含更新后的任务-000055文件；
2. 固定方案声明只在任务-000055增加唯一治理自动化字段；
3. 输入合同声明任务-000055的最新阻塞状态。

三类证据均从main基线任务-000056正文读取。目标任务必须保持阻塞，头部只能增加唯一
`自动合并范围：治理自动化`字段；任务引用、路径白名单、失败关闭、双评审和精确SHA规则
全部保持不变。

## 反例

缺少任一证据、目标任务错误、多个字段、状态迁移、生产/数据路径或未授权变更类型均拒绝。

## 安全与回滚

不访问服务器、数据库或真实数据，不修改任务状态和原始数据。回滚本任务合并提交即可恢复
原资格匹配逻辑；任务-000056保持阻塞，等待新的可信复验。
