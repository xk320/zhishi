# 任务-000089：固定 root 只读候选身份声明索引复验设计

## 目标

在不扩大任务-000084的 root 只读合同边界、不读取业务正文的前提下，优化固定白名单目录的候选文件索引方式，避免非候选文件数量过多导致提前失败安全。该任务只负责发现和复验候选身份输入；不能把“找到文件”解释为来源身份已经证明。

## 固定边界

- 远端逻辑别名只能是 `ubuntu`，实际 UID 必须记录为 0，root 不等价于专用只读 UID=1001。
- 目录、候选文件名、格式、排除路径、探针协议、SSH 参数、候选大小和输出资源上限均复用任务-000084的固定合同。
- 探针只使用标准输入运行的固定 Python 程序；不执行任意 shell、参数替换、远端写入、DDL、权限或服务变更。
- 只保存脱敏元数据、候选字段摘要、计数、指纹、退出码和资源事实，不保存地址、凭据、原始业务记录或未登记路径。
- 索引资源固定为：最多 16,384 个目录、262,144 个目录条目、16,384 个待处理目录、4,096 字节单路径、32 MiB 候选摘要聚合字节；超限立即清空候选并失败安全。

## 预期验证

- 索引遍历不会把普通非候选文件数错误当作候选分母；候选数、遍历完整性和失败原因必须可复算。
- 候选输入仍按 BTC、ETH 独立的 630 个成员与九字段身份合同校验；缺失或不完整时保持 `无法判定`，不得生成空的 `source-identity-evidence-1.0`。
- 任务-000084、`ZS-DATA-GAP-001`、阶段1和阶段2状态不得被本任务迁移。
- 即使发现完整证据，任务-000089交付PR也不得修改任务-000084合同或状态；恢复只能由独立的合并后状态闭环PR完成。

## 交付边界

交付阶段必须在独立执行分支完成合同、配置、探针薄封装、专项测试、不可变脱敏批次和验证记录；所有异常均失败安全。该任务不修改生产代码、数据库、原始数据、订单簿服务、账户权限或可信自动合并脚本。
