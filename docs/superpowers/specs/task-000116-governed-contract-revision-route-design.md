# 任务-000116设计说明：阶段1合同修订受控资格路径

## 设计结论

任务中心不允许普通交付直接改写阻塞任务合同。本设计新增两个固定、不可泛化的治理入口：

1. `任务-000116→任务-000115`：只补齐任务-000115首次阻塞所需的唯一`当前阻塞原因`字段，目标状态仍为待执行，看板逐字不变。
2. `阶段1覆盖受限合同修订`：只允许任务-000115作为执行任务、任务-000106作为固定目标；目标保持阻塞，允许按任务-000115合同更新当前适用规则和派生入口，历史执行记录、批次、SHA与原始数据不变。

## 失败关闭

未知任务、额外引用、重复引用、错目标、错状态、额外任务路径、看板漂移、合同正文漂移、PR头SHA不一致、生产/数据库/服务器/凭据/真实交易路径均失败关闭。既有四类变更类型的规则和评审门不改变。

## 验证绑定

所有资格计算仍使用main上的可信检查器，绑定base/head完整SHA、任务编号、PR正文、路径事实、工作流只读元数据和专项测试。新入口只为后续任务-000115提供最小治理授权，不提前改变任务-000106结论。
