# 任务-000099：事前冻结数据资格决策与重放实施计划

<!-- markdownlint-disable MD013 -->

## 目标

在不读取854GB原始归档的前提下，先冻结一个真实决策意图，再产生新的数据资格决策，最后由两个独立进程重放该决策；补齐路径组件、无覆盖发布和最终资源硬门。

## 实施顺序

1. 建立固定配置和合同，锁定任务-000094的7个脱敏文件、预登记SHA、版本、计数及资源边界。
2. 实现共享严格解码和裁决模块，以及互斥的`prepare`、`decide`、`replay`命令。
3. 用专项负向测试锁定事前冻结、独立进程、未来数据、路径符号链接、目标冲突、源漂移和最终资源超限。
4. 依次启动一次`prepare`、一次`decide`和两个独立`replay`进程，生成追加式真实批次并复算全部指纹。
5. 更新阶段1审计报告、数据缺口、总体计划、README、任务与看板，运行审计/数据/研发中心完整验证。
6. 创建PR，完成双只读评审；自动修复P0/P1，可信复验通过后自动合并并执行独立状态闭环。

## 资源控制

所有测试与正式动作单进程运行；每个正式进程限制RSS 512MiB和120秒，Node堆限制256MiB。只读取任务-000094约1.3MiB脱敏批次，不遍历原始归档根目录。
