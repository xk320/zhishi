# 知势

> **宁可错过，不做低胜率交易。**

知势是一套以“识势而动”为核心方法的智能交易决策系统。

它不追求预测全部行情，不追求提高交易频率，也不以捕捉最大涨幅为目标。知势只寻找具有统计优势、风险边界清晰、逻辑可以验证的交易机会；当优势不足时，默认空仓。

## 项目使命

- 预测资金行为，而不是机械预测价格。
- 从 BTC、ETH、SOL 中寻找未来 4 小时、8 小时、24 小时与 48 小时内最值得交易的标的。
- 每日只筛选 0～2 次高质量机会。
- 优先捕捉风险可控的短周期波动，而不是追逐偶发性暴涨。
- 将每一项研究转化为可验证、可回测、可否决的决策依据。

## 核心原则

1. 宁可错过，不做低胜率交易。
2. 预测资金，而不是预测价格。
3. 没有可证明的优势，默认空仓。
4. 先定义损失边界，再讨论潜在收益。
5. 决策质量高于交易频率。
6. 长期复利高于短期暴利。
7. 每个指标必须回答一个明确问题，否则不纳入系统。

## 系统分层

```text
知势宣言
    ↓
知势方法
    ↓
知势研究
    ↓
知势引擎
```

- **知势宣言**：定义项目不可轻易改变的价值观与边界。
- **知势方法**：定义如何识别市场之势、资金之势与交易许可。
- **知势研究**：用数据检验假设，决定一项能力是否值得纳入系统。
- **知势引擎**：将已验证的方法实现为数据、模型、回测、风控和决策模块。

## 第一阶段范围

- 标的：BTC、ETH、SOL。
- 时间尺度：4 小时、8 小时、24 小时、48 小时。
- 输出：一个首选标的、一个方向、一个确定性、一个仓位建议、一个失效条件、一个退出条件。
- 交易频率：每日 0～2 次。
- 默认状态：空仓。

## 决策原则

系统最终不是输出一堆指标，而是回答六个问题：

1. 今天是否存在值得交易的机会？
2. BTC、ETH、SOL 中哪个标的最优？
3. 应该做多、做空，还是空仓？
4. 当前确定性是多少？
5. 判断在什么条件下失效？
6. 应该在什么条件下退出？

知势不是让系统越来越会“看指标”，而是让系统越来越会做出可以解释、可以验证、可以约束风险的决策。
