# 知势

> **宁可错过，不做低胜率交易。**

知势是一套以“识势而动”为核心方法的智能交易决策系统。

它不追求预测全部行情，不追求提高交易频率，也不以捕捉最大涨幅为目标。知势只寻找具有统计优势、风险边界清晰、逻辑可以验证的交易机会；当优势不足时，默认空仓。

## 项目使命

- 预测资金行为，而不是机械预测价格。
- 从 BTC、ETH、SOL 中寻找未来 4 小时、8 小时、24 小时与 48 小时内最值得交易的标的。
- 每日只筛选 0～2 次高质量机会。
- 优先捕捉风险可控的短周期波动，而不是追逐偶发性暴涨。
- 将每一项研究转化为可验证、可回测、可否决的决策依据。

## 核心原则

1. 宁可错过，不做低胜率交易。
2. 预测资金，而不是预测价格。
3. 没有可证明的优势，默认空仓。
4. 先定义损失边界，再讨论潜在收益。
5. 决策质量高于交易频率。
6. 长期复利高于短期暴利。
7. 每个指标必须回答一个明确问题，否则不纳入系统。
8. 不设置强制每日收益目标，不因踏空或亏损降低准入标准。

## 系统分层

```text
知势宣言
    ↓
知势方法与决策合同
    ↓
知势研究
    ↓
知势引擎
```

- **知势宣言**：定义项目不可轻易改变的价值观与边界。
- **知势方法与决策合同**：定义如何识别市场之势、资金之势，以及何时允许或禁止交易。
- **知势研究**：用数据检验假设，决定一项能力是否值得纳入系统。
- **知势引擎**：将已验证的方法实现为数据、模型、回测、风控和决策模块。

## 第一阶段范围

- 标的：BTC、ETH、SOL。
- 时间尺度：4 小时、8 小时、24 小时、48 小时。
- 输出：一个首选标的、一个方向、校准后的预测胜率、确定性、赔率、仓位、失效条件和退出条件。
- 交易频率：每日 0～2 次。
- 默认状态：空仓。
- 真实资金自动交易：关闭。

## 七道交易许可质量门

任何交易必须依次通过：

1. 数据门。
2. 样本门。
3. 优势门。
4. 成本门。
5. 风险门。
6. 执行门。
7. 频率与纪律门。

任一硬门槛失败，最终结论必须是：

```text
交易许可：禁止
建议仓位：0
```

## 决策原则

系统最终不是输出一堆指标，而是回答七个问题：

1. 当前数据是否足以支持决策？
2. 今天是否存在值得交易的机会？
3. BTC、ETH、SOL 中哪个标的具有可证明的相对优势？
4. 应该做多、做空，还是空仓？
5. 预测胜率、赔率与净期望是否覆盖成本和安全边际？
6. 判断在什么条件下失效？
7. 应该以多大风险、在什么条件下退出？

知势不是让系统越来越会“看指标”，而是让系统越来越会做出可以解释、可以验证、可以约束风险的决策。
